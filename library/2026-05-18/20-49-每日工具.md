🎯 解决什么痛点
每次写数据加载、绘图、模型训练都要重复敲相同代码，浪费时间且容易出错。

⚡ 快速上手
1. 打开 VS Code → `Cmd + Shift + P` → 输入 `Snippets: Configure User Snippets`
2. 选择 `python.json`，粘贴以下内容：
```json
{
  "Load CSV with pandas": {
    "prefix": "pdload",
    "body": [
      "import pandas as pd",
      "df = pd.read_csv('${1:file.csv}')",
      "df.head()"
    ],
    "description": "快速加载CSV并预览"
  }
}
```
3. 在 `.py` 文件中输入 `pdload` 按 `Tab` 即可展开。

💪 为什么比默认方式好
不用记忆完整语法或复制粘贴，输入3个字符自动生成标准代码块，减少打字错误。

🧪 数据科学场景
最常用：`pdload` 加载数据 → `skfit` 训练模型 → `pltfig` 绘图，一套流水线秒出。
