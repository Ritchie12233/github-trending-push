🎯 解决什么痛点
不用再写 `print()` 调试，也不用配置 logging 的 Handler/Formatter，一行代码直接输出带颜色、时间、文件位置的日志。

⚡ 快速上手
```python
pip install loguru
from loguru import logger
logger.info("数据加载完成，共 {} 行", df.shape[0])
```

💪 为什么比默认方式好
logging 需要 5 行配置，loguru 只需 1 行 import，且自动输出文件名、行号、时间，彩色高亮。

🧪 数据科学场景
在 Jupyter Notebook 或训练脚本中替代 print，实时追踪数据清洗进度、模型训练 loss 变化，且日志自动写入文件方便复盘。
