🎯 解决什么痛点
在 Notebook 里反复手动计时、复制代码到文件、翻找历史命令，浪费大量时间。

⚡ 快速上手
```python
# 测性能：比较列表推导 vs 循环
%timeit [x**2 for x in range(1000)]

# 写文件：将当前单元格内容保存为 .py
%%writefile my_script.py
print("hello")

# 查历史：查看最近 5 条输入
%history -n -l 5
```

💪 为什么比默认方式好
不用 `time.time()` 手动算差、不用复制粘贴到编辑器、不用靠记忆回溯，三合一省心。

🧪 数据科学场景
调参时用 `%timeit` 快速对比 pandas 向量化 vs 循环；写完清洗代码用 `%%writefile` 导出为可复用模块；实验中断后 `%history` 找回关键步骤。
