🎯 解决什么痛点
man 手册又长又啰嗦，你只想快速知道某个命令最常用的几个用法。

⚡ 快速上手
```bash
brew install tldr          # Mac 安装
tldr tar                   # 看 tar 的常用示例
tldr -u                    # 更新本地缓存
```

💪 为什么比默认方式好
man 给你整本说明书，tldr 只给你 5 个最常用例子，3 秒看懂。

🧪 数据科学场景
处理数据时经常忘记 `tar`、`find`、`grep`、`awk`、`rsync` 的语法——比如打包数据集、按条件找文件、批量重命名，`tldr find` 直接给你能抄的示例，不用翻长文档。
