🎯 解决什么痛点
`git diff` 默认输出黑白难读，改了几行代码要盯半天才找得到差异。

⚡ 快速上手
```bash
brew install git-delta
# 写入 git 配置，之后 git diff 自动生效
git config --global core.pager delta
git config --global interactive.diffFilter "delta --color-only"
```

💪 为什么比默认方式好
自带语法高亮 + 行号 + 并排对比，比原生 diff 一眼看清改动，无需装 IDE。

🧪 数据科学场景
改 Jupyter 导出的 `.py` 或 `requirements.txt` 时，快速确认哪行参数、哪个依赖版本被改动，避免误提交。
