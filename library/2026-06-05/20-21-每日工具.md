🎯 解决什么痛点
requests 不支持 async，爬取多个 API 或网页时只能串行等待，效率低。

⚡ 快速上手
```python
import httpx
# 同步请求
r = httpx.get('https://api.github.com')
# 异步请求（快 3-5 倍）
async with httpx.AsyncClient() as client:
    r = await client.get('https://api.github.com')
```

💪 为什么比默认方式好
原生支持 async/await，并发请求无需额外线程池，代码更简洁。

🧪 数据科学场景
批量下载 Kaggle 数据集或爬取论文摘要时，用 `asyncio.gather` 同时发 10 个请求，耗时从 5 秒降到 0.5 秒。
