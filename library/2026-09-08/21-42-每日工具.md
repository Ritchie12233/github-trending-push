🎯 解决什么痛点
换电脑或分享项目时，依赖环境不一致导致代码跑不起来，手动列包又漏又慢。

⚡ 快速上手
```bash
# 导出当前环境所有依赖到文件
pip freeze > requirements.txt

# 在新环境一键安装
pip install -r requirements.txt
```

💪 为什么比默认方式好
比 `pip list` 手动复制快10倍，且格式直接兼容 `pip install`，零额外配置。

🧪 数据科学场景
每次提交 Kaggle/论文代码前执行一次，队友 `pip install -r requirements.txt` 就能复现你的 pandas、sklearn 版本，避免“在我电脑上能跑”的尴尬。
