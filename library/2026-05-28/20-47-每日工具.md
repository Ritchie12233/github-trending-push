🎯 解决什么痛点
长循环或训练时不知道还要等多久，干着急。

⚡ 快速上手
```python
from tqdm import tqdm
for i in tqdm(range(1000)):
    time.sleep(0.01)  # 模拟耗时操作
```

💪 为什么比默认方式好
自带ETA、速度、完成百分比，比print()刷屏优雅100倍。

🧪 数据科学场景
训练深度学习模型时，用`tqdm(train_loader)`直接监控每个epoch的batch进度，配合`desc`参数显示当前loss。
