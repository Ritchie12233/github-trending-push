🎯 解决什么痛点
不同项目依赖版本冲突（如项目A要pandas 1.0，项目B要pandas 2.0），全局安装会互相覆盖导致报错。

⚡ 快速上手
```bash
# 创建虚拟环境（项目目录下）
python3 -m venv .venv

# 激活环境
source .venv/bin/activate

# 安装依赖（隔离安装）
pip install pandas numpy scikit-learn
```

💪 为什么比默认方式好
`conda create -n myenv` 更重但支持非Python包；`venv` 轻量原生，Mac自带无需额外安装。

🧪 数据科学场景
每门课作业独立环境：ML作业装tensorflow 2.x，统计作业装statsmodels 0.14，互不干扰，删除项目时直接删文件夹即可。
