🎯 解决什么痛点
不用在服务器上装图形界面或传文件，本地写代码直接跑在远程 GPU/大内存机器上。

⚡ 快速上手
1. VS Code 安装扩展：`Remote - SSH`
2. 按 `Cmd+Shift+P` → `Remote-SSH: Connect to Host` → 输入 `user@server_ip`
3. 连接后打开远程文件夹，像本地一样编辑代码

💪 为什么比默认方式好
比 vim/nano 有完整 IDE 体验（智能提示、调试、终端）；比 scp 来回传文件省去同步烦恼。

🧪 数据科学场景
在 Mac 上写 PyTorch 训练脚本，直接连到实验室的 Linux 服务器跑 GPU 训练，本地只做编辑和结果可视化。
