🎯 解决什么痛点
在终端里查看 DataFrame、长字典或训练日志时，输出挤成一团、难以阅读，rich 让终端输出变得清晰美观。

⚡ 快速上手
```bash
pip install rich
```
```python
from rich import print
print({"model": "XGBoost", "f1": 0.91, "params": {"depth": 6, "lr": 0.05}})
```

💪 为什么比默认方式好
比 print() 和 pprint() 自动换行、配色、对齐，无需手动格式化。

🧪 数据科学场景
用 rich.table 把模型对比结果（accuracy/F1/耗时）打印成表格，或用 rich.progress 给 pandas 逐块处理和模型训练加进度条，跑长任务时不再干等。
