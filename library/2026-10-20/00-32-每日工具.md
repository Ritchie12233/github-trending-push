🎯 解决什么痛点
用 os.path 拼路径要反复写 os.path.join、os.path.exists，又长又容易在 Mac 和 Windows 之间踩坑。

⚡ 快速上手
```python
from pathlib import Path
data = Path("~/Desktop/data").expanduser()
csvs = list(data.glob("*.csv"))   # 找所有 CSV
(data / "clean").mkdir(exist_ok=True)  # 用 / 拼路径
```

💪 为什么比默认方式好
路径是对象，用 `/` 拼接、自带 glob/mkdir/读写，比 os.path 字符串拼接更短更安全。

🧪 数据科学场景
批量读取一个文件夹里的所有 CSV 做合并：`pd.concat(pd.read_csv(f) for f in Path("raw").glob("*.csv"))`，再也不用手写文件名列表。
