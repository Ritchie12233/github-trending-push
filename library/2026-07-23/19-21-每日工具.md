🎯 解决什么痛点
man 手册太长、信息过载，只想快速知道某个命令怎么用，而不是读一本说明书。

⚡ 快速上手
```bash
# 安装（用 Homebrew）
brew install tldr

# 使用：查看 tar 命令的常用示例
tldr tar
```

💪 为什么比默认方式好
man 输出几十屏，tldr 只给 5-8 个最常用示例，3 秒找到答案。

🧪 数据科学场景
忘记 `scp` 传文件到服务器、`grep` 过滤 CSV 行、`find` 批量重命名数据文件时，直接 `tldr scp` 看示例，不用翻书或搜 Stack Overflow。
