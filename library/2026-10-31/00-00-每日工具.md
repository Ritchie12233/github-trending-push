🎯 解决什么痛点
API 返回一大坨 JSON，肉眼找不到字段、Python 里 print 出来一团乱，想快速看清结构或提取某个值。

⚡ 快速上手
```bash
brew install jq
curl -s "https://api.github.com/users/torvalds" | jq '.name, .public_repos'
curl -s "https://api.example.com/data" | jq '.results[] | {id, score}'
```

💪 为什么比默认方式好
不用写 Python 脚本、不用进交互环境，一行管道直接过滤/格式化 JSON，比 `python -m json.tool` 强在能查询和变换。

🧪 数据科学场景
调 API 抓数据时先用 `jq '.results[0]'` 看清返回结构再写解析代码；批量提取字段 `jq -r '.items[].id'` 直接生成 ID 列表喂给下一个脚本；`jq '.'` 一键美化，排查嵌套字段比翻文档快得多。
