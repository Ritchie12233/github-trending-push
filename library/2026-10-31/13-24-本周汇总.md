**1. 文档转Markdown（microsoft/markitdown）⭐193k**
- **一句话**：把 PDF、Word、Excel、PPT 等文件一键转成 Markdown 的 Python 工具。
- **为什么必看**：数据科学研究中大量非结构化文档（论文、报告、表格）需要进入 LLM/RAG 管道，这个工具是当前最省心的预处理方案，已被 AutoGen、LangChain 生态集成。
- **研究生用法**：批量把文献 PDF 转成 Markdown 后喂给本地 LLM 做摘要/问答；或作为你论文数据清洗 pipeline 的一环。
- **上手门槛**：低，`pip install markitdown` 即可。

**2. 从零实现LLM（rasbt/LLMs-from-scratch）⭐107k**
- **一句话**：用 PyTorch 从零一步步实现一个类 ChatGPT 的大语言模型。
- **为什么必看**：这是目前最系统的 LLM 原理教程，覆盖 tokenizer、注意力机制、预训练、指令微调全流程，代码与讲解并排，适合作为你理解 Transformer 内部机制的"教科书"。
- **研究生用法**：作为深度学习课程的补充读物；做 LLM 相关论文时，能帮你快速定位每个模块的实现细节。
- **上手门槛**：中，需要 PyTorch 基础。

**3. 代码知识图谱（Graphify-Labs/graphify）⭐139k**
- **一句话**：把任意代码库（含文档、SQL schema、PDF）转成可查询的知识图谱，无需向量库。
- **为什么必看**：它代表了 RAG 的一个新方向——用确定性 AST 解析 + 图谱替代向量检索，每条边都可解释。对做代码理解、知识图谱、可解释 AI 方向的研究生非常有启发。
- **研究生用法**：研究 GraphRAG 与向量 RAG 的对比；或把它作为你代码分析类课题的 baseline 工具。
- **上手门槛**：中，需理解 AST 与图谱概念。

📊 本周趋势观察
本周最显著的趋势是 **AI Agent 工程化进入"技能化"阶段**——大量项目围绕 agent skills、subagent 编排、MCP 协议展开，Agent 从"能对话"走向"能执行标准化技能"。其次，**RAG 正在从向量检索转向图谱与确定性解析**（如代码知识图谱项目），可解释性成为新卖点。数据科学侧，**文档解析与工作流编排**持续是基础设施热点，说明"数据进入模型前的处理"仍是痛点。整体看，开源社区正把 AI 能力快速"工具化、平民化"。

📖 学习建议
1. **先打通"文档→数据→模型"链路**：用「文档转Markdown」把你这周要读的 3-5 篇论文 PDF 转成 Markdown，再喂给本地 LLM 做摘要，亲手体验一次完整的 RAG 预处理流程——这比看十篇教程都有效。
2. **用「从零实现LLM」补原理短板**：作为非 CS 背景研究生，建议每周精读其中 1-2 章（如注意力机制、tokenizer），配合「ML入门12周」打基础，两条线并行，一个月后你对 LLM 的理解会有质变。
