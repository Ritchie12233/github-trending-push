🎯 解决什么痛点
数据集和 notebook 散落在多层目录里，每次 cd 都要敲一长串路径，还容易记错。

⚡ 快速上手
```bash
brew install zoxide
echo 'eval "$(zoxide init zsh)"' >> ~/.zshrc && source ~/.zshrc
# 之后只需：z titanic   （自动跳到最常去的含 titanic 的目录）
```

💪 为什么比默认方式好
cd 要求完整路径，zoxide 记住你去过哪、去得多频繁，输几个关键词就跳过去。

🧪 数据科学场景
在 `~/projects/`、`~/data/raw/`、`~/notebooks/` 之间来回切换时，直接 `z raw` 或 `z notebook` 秒到，不用再翻历史命令或拼路径。
