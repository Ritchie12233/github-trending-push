🎯 解决什么痛点
写代码时手不用离开键盘去翻菜单找功能，所有操作一个搜索框搞定。

⚡ 快速上手
按 `Cmd + Shift + P`，然后直接输入你想做的事，比如：
```
> Jupyter: Create New Blank Notebook
> Python: Select Interpreter
> Format Document
```
输入关键词（中英文都行），回车即执行。

💪 为什么比默认方式好
比一层层点菜单栏快 5 倍，且能搜到藏在深处的命令和扩展功能。

🧪 数据科学场景
切换 Python 解释器、重启 Jupyter Kernel、格式化代码、装扩展——这些高频操作全都能一个快捷键直达，不用记路径。
