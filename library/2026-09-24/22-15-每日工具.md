🎯 解决什么痛点
代码写得乱、import 顺序乱、变量没用就定义——以前要装 flake8+black+isort 三个工具，现在一个 ruff 全搞定。

⚡ 快速上手
```bash
pip install ruff
ruff check .        # 检查问题
ruff check . --fix  # 自动修复
ruff format .       # 格式化代码
```

💪 为什么比默认方式好
比 flake8+black+isort 组合快 10-100 倍（Rust 写的），配置只需一个 `pyproject.toml`。

🧪 数据科学场景
Jupyter 里写了几百行探索代码，导出成 `.py` 后跑一次 `ruff format .`，瞬间变成能交给导师看的整洁脚本；`ruff check --fix` 还能自动删掉没用的 import，避免 notebook 里常见的"import 了一堆没用上的库"。
