🎯 解决什么痛点
写类时手动定义 `__init__`、`__repr__` 等样板代码，既啰嗦又易出错。

⚡ 快速上手
```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    gpa: float
    courses: list[str] = []  # 自动有 __init__ 和 __repr__

s = Student("Ali", 3.8)
print(s)  # Student(name='Ali', gpa=3.8, courses=[])
```

💪 为什么比默认方式好
比普通 class 少写 50% 代码，且自带类型提示，调试时自动打印清晰字段。

🧪 数据科学场景
定义特征向量、模型配置或实验结果记录时，用 dataclass 组织字段，配合 `asdict()` 一键转字典存 JSON 或 pandas DataFrame。
