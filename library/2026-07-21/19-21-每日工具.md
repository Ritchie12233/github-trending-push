🎯 解决什么痛点
不用再记或敲长路径，输入模糊关键词即可跳转到最常去的目录。

⚡ 快速上手
```bash
brew install zoxide
# 在 .zshrc 添加一行
eval "$(zoxide init zsh)"
# 使用：z data  # 自动跳转到 ~/projects/data_science
```

💪 为什么比默认方式好
cd 需要完整路径或手动 tab 补全；zoxide 按使用频率智能匹配，越用越准。

🧪 数据科学场景
每天在 `~/projects/ds_homework`、`~/data/kaggle`、`~/notebooks/thesis` 之间切换，只需 `z hw`、`z kaggle`、`z thesis` 即可秒跳，省去每次打长路径的麻烦。
