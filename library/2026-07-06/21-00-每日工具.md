🎯 解决什么痛点
用类型注解自动校验数据，避免手动写if-else检查类型和字段，运行时自动报错。

⚡ 快速上手
```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

user = User(name="Alice", age="25")  # age自动转int
user = User(name="Bob", age="abc")   # 立刻报ValidationError
```

💪 为什么比默认方式好
比dataclass多了自动校验和类型转换，比手动assert省10倍代码量。

🧪 数据科学场景
清洗CSV/API数据时，用pydantic定义Schema，一行代码校验整批数据，避免脏数据污染模型训练。
