🎯 解决什么痛点
调试代码时，看到奇怪逻辑或bug，不知道是谁写的、什么时候改的，无法快速追溯责任人。

⚡ 快速上手
在 VS Code 扩展市场搜索 "GitLens" 安装，打开任意 Python 文件，光标停在某行代码上，编辑器上方会直接显示：作者名、日期、commit message。

💪 为什么比默认方式好
VS Code 内置 Git blame 需手动运行命令，GitLens 直接在行内显示，无需切换窗口，零操作成本。

🧪 数据科学场景
复现实验时，发现某个数据预处理函数输出异常，用 GitLens 看到最后修改者是队友，commit message 写着 "修复空值填充逻辑"，直接定位问题来源，省去翻 git log 的时间。
