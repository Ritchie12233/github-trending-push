🎯 解决什么痛点
写完的数据处理脚本只能改代码传参数，想做成命令行工具又嫌 argparse 太啰嗦。

⚡ 快速上手
```bash
pip install typer
```
```python
import typer

def clean(csv: str, drop_na: bool = False, threshold: float = 0.5):
    print(f"处理 {csv}，drop_na={drop_na}，阈值={threshold}")

typer.run(clean)
```
```bash
python clean.py data.csv --drop-na --threshold 0.8
```

💪 为什么比默认方式好
argparse 要手写一堆 add_argument，typer 靠类型注解自动生成参数、帮助和校验。

🧪 数据科学场景
把「读 CSV → 清洗 → 训练模型 → 输出指标」的脚本包成 CLI，换数据集或调超参时不用打开编辑器，直接命令行传参，也方便交给同学或助教复现。
