🎯 解决什么痛点
接手别人的 notebook 或脚本时，不知道某行代码是谁、何时、为何改的，只能靠猜。

⚡ 快速上手
在 VS Code 扩展面板搜索 `GitLens` 安装，或命令行：
```bash
code --install-extension eamodio.gitlens
```
打开任意 `.py` 文件，光标停在某行 → 行尾自动显示 `作者, 时间, commit 信息`；点 `Open Changes` 看该行历史。

💪 为什么比默认方式好
不用切终端敲 `git blame`，行内直接看 blame + 悬停看完整 commit，还能一键跳转 diff。

🧪 数据科学场景
调参或改特征工程时，发现某行 `df.dropna()` 被同事删过又加回来——GitLens 一眼看到是谁、哪次 commit、commit message 写了什么原因，避免重复踩坑。
