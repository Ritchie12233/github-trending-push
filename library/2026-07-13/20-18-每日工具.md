🎯 解决什么痛点
处理百万行以上数据时，pandas 慢到让人崩溃，内存还经常炸。

⚡ 快速上手
```python
# 安装
pip install polars

# 读取CSV并分组聚合
import polars as pl
df = pl.read_csv("large_file.csv")
result = df.group_by("category").agg(pl.col("value").mean())
```

💪 为什么比默认方式好
pandas 单线程 + Python 循环，polars 用 Rust + 多核并行，速度快 5-10 倍，内存省一半。

🧪 数据科学场景
处理 500MB 以上的日志文件或交易数据时，polars 秒出结果，pandas 要等 30 秒甚至 OOM。
