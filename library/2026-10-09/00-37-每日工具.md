🎯 解决什么痛点
每次写 Python 都要重复敲 `import pandas as pd`、`plt.show()` 这些样板代码，浪费时间还容易打错。

⚡ 快速上手
1. 按 `Cmd+Shift+P` → 输入 "Snippets" → 选 **Preferences: Configure User Snippets** → 选 `python.json`
2. 粘贴以下内容：

```json
{
  "Pandas + Numpy 起手式": {
    "prefix": "pdnp",
    "body": [
      "import pandas as pd",
      "import numpy as np",
      "",
      "$0"
    ]
  },
  "Matplotlib 快速画图": {
    "prefix": "pltfig",
    "body": [
      "import matplotlib.pyplot as plt",
      "plt.figure(figsize=(${1:10}, ${2:6}))",
      "plt.plot(${3:x}, ${4:y})",
      "plt.title('${5:Title}')",
      "plt.xlabel('${6:xlabel}')",
      "plt.ylabel('${7:ylabel}')",
      "plt.show()",
      "$0"
    ]
  }
}
```

3. 在 `.py` 文件里输入 `pdnp` 或 `pltfig`，按 `Tab` 自动展开。

💪 为什么比默认方式好
比手动复制粘贴快，比装第三方插件轻，VS Code 原生支持、零配置依赖。

🧪 数据科学场景
每次开新 notebook 或 `.py` 分析脚本时，`pdnp` 一键导入数据科学三件套；做 EDA 时 `pltfig` 秒出画图骨架，把时间留给真正的建模和调参。
