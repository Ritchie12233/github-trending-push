🎯 解决什么痛点
代码风格检查+格式化慢且工具分散，ruff 一个命令搞定，速度比 flake8 快 10-100 倍。

⚡ 快速上手
```bash
pip install ruff
ruff check .          # 检查代码问题
ruff format .         # 自动格式化
```

💪 为什么比默认方式好
替代 flake8+black+isort 三件套，配置统一，速度极快，适合大项目。

🧪 数据科学场景
写 Jupyter Notebook 或脚本时，一键检查未使用变量、import 排序，保持代码整洁，避免提交垃圾代码。
