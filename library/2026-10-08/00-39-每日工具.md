🎯 解决什么痛点
不用开浏览器、不用切窗口，在 VS Code 里直接跑 .ipynb，还能实时看变量和图表。

⚡ 快速上手
```bash
# 1. 安装扩展（VS Code 里搜 "Jupyter" 或命令行）
code --install-extension ms-toolsai.jupyter

# 2. 打开任意 .ipynb 文件，右上角选 Python 内核，Shift+Enter 逐格运行
```

💪 为什么比默认方式好
比浏览器版 Jupyter 多了变量浏览器和调试器，不用来回切标签页。

🧪 数据科学场景
清洗数据时用变量浏览器直接展开 DataFrame 看每列 dtype 和缺失值，比反复 `df.info()` 快得多；画图后直接在单元格下方内联显示，调参时改一行重跑一格，不用重启整个 notebook。
