🎯 解决什么痛点
用 chain/groupby/product 替代多层嵌套 for 循环，让数据预处理代码从 10 行缩成 1 行。

⚡ 快速上手
```python
from itertools import chain, groupby, product

# 展平嵌套列表
nested = [[1,2], [3,4], [5]]
list(chain.from_iterable(nested))  # [1,2,3,4,5]

# 按首字母分组
data = ['apple', 'banana', 'avocado', 'blueberry']
{k: list(v) for k, v in groupby(sorted(data), key=lambda x: x[0])}
# {'a': ['apple', 'avocado'], 'b': ['banana', 'blueberry']}

# 笛卡尔积（替代双重for）
list(product([1,2], ['x','y']))  # [(1,'x'),(1,'y'),(2,'x'),(2,'y')]
```

💪 为什么比默认方式好
手写 for 循环易出错且慢，itertools 用 C 实现，内存高效且代码意图一目了然。

🧪 数据科学场景
特征工程中生成所有特征组合：`list(product(features, repeat=2))` 秒出交叉特征候选集。
