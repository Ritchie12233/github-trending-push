🎯 解决什么痛点
换电脑、交作业或复现实验时，忘记装了哪些包、版本对不上，环境重建全靠猜。

⚡ 快速上手
```bash
# 在已激活的虚拟环境中执行
pip freeze > requirements.txt

# 别人（或未来的你）一键还原
pip install -r requirements.txt
```

💪 为什么比默认方式好
比手动记包名靠谱，比 conda env export 更轻量、跨平台，纯 Python 项目首选。

🧪 数据科学场景
跑完一个 Kaggle 项目或课程作业后，导出 requirements.txt 一起提交，助教/组员能精确复现你的 pandas、scikit-learn、xgboost 版本，避免"在我电脑上能跑"的尴尬。

💡 小提醒：导出前先 `pip install pipreqs && pipreqs .` 可只保留项目真正用到的包，避免 requirements.txt 塞满无关依赖。
