🎯 解决什么痛点
在 Notebook 里反复手动计时、复制代码到文件、翻找历史命令，浪费时间且易出错。

⚡ 快速上手
```python
# 测性能：对比两种写法
%timeit sum(range(1000))          # 单行
%%timeit                          # 多行代码块
x = [i**2 for i in range(1000)]

# 写文件：直接保存当前单元格内容
%%writefile my_script.py
def hello():
    print("Hi!")

# 查历史：查看最近5条命令
%history -n -l 5
```

💪 为什么比默认方式好
不用手动 `time.time()` 或复制粘贴到编辑器，一条命令搞定，且自动多次运行取平均，结果更可靠。

🧪 数据科学场景
- 调参时快速比较 `pandas` 与 `numpy` 的运算速度，决定用哪种实现
- 把清洗数据的代码块一键存为 `.py` 文件，方便复用或部署
- 写论文时回溯自己跑过的实验步骤，避免重复劳动
