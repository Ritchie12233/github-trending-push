🎯 解决什么痛点
不同项目依赖版本冲突（如A要pandas 1.5，B要2.0），全局安装会互相覆盖，导致项目跑不起来。

⚡ 快速上手
```bash
# 创建并激活（Mac/Linux）
python3 -m venv myenv
source myenv/bin/activate

# 退出
deactivate
```

💪 为什么比默认方式好
`conda` 适合管理Python版本+包，但`venv`轻量无额外依赖；对比全局pip，隔离后`pip freeze` 能精准导出当前项目依赖，部署不踩雷。

🧪 数据科学场景
每次开新项目（如Kaggle竞赛或论文复现），先建独立环境，再`pip install pandas scikit-learn`，保证换电脑或换队友时，`requirements.txt` 一键复现，不污染系统Python。
