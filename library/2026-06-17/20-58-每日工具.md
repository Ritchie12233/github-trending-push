🎯 解决什么痛点
man 手册太长、信息过载，只想快速看某个命令怎么用、给什么参数。

⚡ 快速上手
```bash
brew install tldr          # 安装
tldr tar                   # 查看 tar 命令的常用示例
tldr --update              # 更新本地缓存
```

💪 为什么比默认方式好
man 输出像百科全书，tldr 像速查卡片——直接给 5-10 个最常用场景的代码示例，省去翻页时间。

🧪 数据科学场景
忘记 `scp` 传文件夹、`find` 按日期过滤文件、`awk` 提取 CSV 列时，`tldr scp` 秒出答案，不用再 Google 或翻 man。
