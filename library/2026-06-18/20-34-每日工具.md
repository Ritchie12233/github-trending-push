🎯 解决什么痛点
数据集、日志、缓存文件散落各处，手动 `du -sh` 逐个文件夹查太慢，ncdu 一键交互式扫描，直接定位哪个目录吃掉了你的 SSD。

⚡ 快速上手
```bash
# 安装
brew install ncdu

# 扫描当前目录（默认跳过隐藏文件）
ncdu

# 扫描整个家目录，显示隐藏文件
ncdu ~ -a
```
进入界面后：方向键导航，`d` 删除，`?` 查看快捷键。

💪 为什么比默认方式好
`du` 只能看单层，`ncdu` 像文件管理器一样上下钻取、排序、删除，速度比 GUI 工具（如 DaisyDisk）快 10 倍，且纯终端无需图形界面。

🧪 数据科学场景
跑完 10 个模型后，`ncdu ~/data` 秒查哪个实验的 `.csv` 或 `.pkl` 文件占了几十 GB，直接按 `d` 清理无用中间产物，避免磁盘写满导致训练中断。
