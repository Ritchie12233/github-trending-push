🎯 解决什么痛点
数据从 CSV/API/JSON 进来时字段缺失、类型错乱、脏值混入，靠 if-else 手写校验又臭又长。

⚡ 快速上手
```bash
pip install pydantic
```
```python
from pydantic import BaseModel, Field

class Student(BaseModel):
    name: str
    age: int = Field(ge=18, le=60)
    gpa: float = Field(ge=0, le=4.0)

Student(name="Ali", age=24, gpa=3.7)   # ✅ 自动校验+类型转换
Student(name="Ali", age="abc", gpa=3.7) # ❌ 立刻报清晰错误
```

💪 为什么比默认方式好
不用写一行 if 判断，类型注解即校验规则，错误信息直接告诉你哪个字段哪里错。

🧪 数据科学场景
读入原始数据后先用 pydantic 模型逐条校验（或配合 `model_validate` 批量处理），在进入 pandas 分析前就把脏数据拦下来，避免后面模型训练时才发现 NaN 或类型错误。
