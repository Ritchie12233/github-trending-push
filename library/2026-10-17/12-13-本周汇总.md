**1. 数据科学手册（awesome-datascience）** ⭐30k
- **一句话**：数据科学领域最全的学习资源与实战问题索引库。
- **亮点**：涵盖数据挖掘、可视化、深度学习、ML 等主题的精选资源列表，按学习路径和应用场景分类，适合研究生快速定位自己研究方向所需的工具与资料。
- **与你相关**：作为数据科学研究生，这是你建立「知识地图」的起点——从课程、数据集到竞赛平台一应俱全，可直接用于选题调研和文献补充。
- **上手建议**：先浏览目录找到自己研究方向（如时间序列/因果推断/NLP），再深挖对应子列表。

**2. 图化知识库（graphify）** ⭐127k
- **一句话**：把任意代码库、SQL schema、PDF 转成可查询知识图谱。
- **亮点**：本地确定性 AST 解析，每条边都有解释，不依赖向量库；支持 Claude Code、Cursor、Codex 等主流 Agent 工具。对需要理解大型代码库或构建 RAG 系统的研究者极有价值。
- **与你相关**：数据科学研究中常需处理异构文档（论文 PDF、数据库 schema、实验代码），这个工具能帮你把它们统一成可查询图谱，直接服务于你的 RAG 或知识管理 pipeline。
- **上手建议**：先用一个小型项目（如你的实验代码库）试跑，观察生成的图谱结构是否符合预期。

**3. 表格分析库（pandas）** ⭐50k
- **一句话**：Python 数据分析与操作的绝对核心库。
- **亮点**：本周持续高频更新（pushed_at 10-17），作为数据科学研究的「空气级」依赖，其稳定性与新特性直接影响你的日常分析效率。
- **与你相关**：无论你做数据清洗、特征工程还是探索性分析，pandas 都是不可绕过的工具。关注其更新能帮你避免踩坑、用上新优化。
- **上手建议**：检查你当前项目是否用到了最新版本的新 API（如 Copy-on-Write 行为变化），及时适配。

**4. 机器学习入门（ai-engineering-from-scratch）** ⭐70k
- **一句话**：从零构建 AI 工程能力的系统课程。
- **亮点**：覆盖 agents、CV、深度学习、LLM、MCP、强化学习等，强调「学—建—交付」闭环，适合作为研究生阶段的自学补充。
- **与你相关**：如果你想把课堂理论转化为可落地的工程项目能力，这套课程的结构化路径很值得收藏，按需取用。
- **上手建议**：不必全刷，挑与你论文方向最相关的 2-3 个模块精读。

**5. 可视化平台（superset）** ⭐75k
- **一句话**：Apache 出品的企业级数据可视化与探索平台。
- **亮点**：支持 SQL 编辑器、丰富图表类型、BI 仪表盘，适合把分析结果做成可交互的展示。
- **与你相关**：论文答辩或项目汇报时，一个漂亮的交互式 dashboard 比静态图更有说服力。
- **上手建议**：用 Docker 本地起一个实例，把你的一份分析结果做成 dashboard 练手。

**6. 量化研究台（qlib）** ⭐49k
- **一句话**：微软开源的 AI 量化投资研究平台。
- **亮点**：支持监督学习、市场动态建模、强化学习等多种范式，并集成 RD-Agent 自动化研发流程。
- **与你相关**：如果你的研究方向涉及金融数据、时间序列或强化学习，这是一个高质量的端到端实验平台。
- **上手建议**：先跑通官方示例 pipeline，理解其数据格式与模型接口。

**7. 数据应用框架（reflex）** ⭐46k
- **一句话**：用纯 Python 构建 Web 数据应用。
- **亮点**：无需 JavaScript，适合数据科学背景快速把模型或分析做成可分享的 Web app。
- **与你相关**：做 demo、展示原型或给导师演示成果时，比 Streamlit 更灵活的全栈方案。
- **上手建议**：对比 Streamlit 和 Reflex 的适用场景，选一个作为你的默认 demo 工具。

**8. 算法动画教程（hello-algo）** ⭐131k
- **一句话**：动画图解、多语言实现的数据结构与算法教程。
- **亮点**：支持简中/繁中/英/日，提供 Python、Java、C++ 等十余种语言代码，动画讲解降低理解门槛。
- **与你相关**：非 CS 背景补算法基础的最佳入口，中文友好、门槛低但内容扎实。
- **上手建议**：每天花 20 分钟跟一个章节，配合代码跑一遍。

**9. 项目式学习（project-based-learning）** ⭐287k
- **一句话**：按项目组织的编程教程精选列表。
- **亮点**：覆盖 Python、JS、Go、C++ 等语言，每个教程都是一个完整可交付的小项目。
- **与你相关**：比纯看视频更高效的学习方式——通过做项目建立编程直觉，适合转码或补工程能力。
- **上手建议**：选一个与你研究方向相关的小项目（如数据爬取+可视化），完整做一遍。

**10. 免费编程书（free-programming-books）** ⭐399k
- **一句话**：免费编程书籍资源大全。
- **亮点**：按语言和主题分类，涵盖从入门到进阶的海量免费书籍，多语言支持。
- **与你相关**：零成本建立个人技术书库，适合系统补 CS 基础或深入某个专题。
- **上手建议**：先收藏，按「当前最缺的知识点」挑一本精读，别贪多。

📊 本周趋势观察
本周开源社区最显著的动向是「AI Agent 工具链的垂直分层」——从通用技能框架（superpowers、ECC）到垂直场景工具（graphify 做知识图谱、rea 做逆向工程），Agent 生态正从「能跑」走向「好用」。与此同时，数据科学基础设施（pandas、scikit-learn、Superset、qlib）保持高频更新，说明传统 DS 工具链仍是研究与生产的刚需底座。值得注意的还有「Agent 管理 Agent」类项目（如 claw-code 无人工干预维护）开始出现，预示着自动化研发流程的新范式。对研究生而言，本周的核心信号是：**把 Agent 当作研究加速器，而非替代品**。

📖 学习建议
1. **用「图化知识库」重构你的文献管理**：把论文 PDF、实验代码、数据 schema 喂给 graphify，构建个人研究知识图谱，比传统文件夹管理更能发现跨文档的隐性关联——这对写文献综述和找研究缺口特别有用。
2. **非 CS 背景优先补「算法动画教程」+「项目式学习」组合**：前者建立数据结构与算法的直觉（每天 20 分钟），后者通过完整小项目把知识落地。两者搭配能在 1-2 个月内显著提升你读代码、写 pipeline 的底气，比单纯刷课更扎实。
