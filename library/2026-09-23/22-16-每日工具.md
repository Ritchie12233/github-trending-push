🎯 解决什么痛点
pandas 处理几十万行以上数据时又慢又吃内存，polars 用 Rust 多核并行，同样数据快 5–30 倍、内存占用更低。

⚡ 快速上手
```bash
pip install polars
```
```python
import polars as pl
df = pl.read_csv("data.csv")
df.filter(pl.col("score") > 80).group_by("major").agg(pl.col("score").mean())
```

💪 为什么比默认方式好
惰性执行 + 多线程，无需改代码风格就能跑满 CPU，大数据不再卡死。

🧪 数据科学场景
清洗和聚合大 CSV/Parquet 数据集（如几百万行日志或调查数据）时，用 `pl.scan_csv(...).lazy()` 流式处理，内存不够的 Mac 也能跑完。
