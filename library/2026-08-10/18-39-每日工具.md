🎯 解决什么痛点
终端输出全是黑白纯文本，调试和展示结果时难以快速定位关键信息。

⚡ 快速上手
```bash
pip install rich
```
```python
from rich import print
print("[bold red]警告：[/bold red]数据缺失！")
from rich.table import Table
t = Table(title="模型对比")
t.add_column("模型"); t.add_column("准确率")
t.add_row("XGBoost", "0.92"); print(t)
```

💪 为什么比默认方式好
一行代码替代 print + 手动格式化，表格和进度条无需额外库。

🧪 数据科学场景
训练时用 `rich.progress` 显示 epoch 进度条，或打印模型评估结果表格，一眼看清各指标差异。
