🎯 解决什么痛点
终端里找历史命令、搜文件、切分支时总要手动输入完整路径或命令，效率极低。

⚡ 快速上手
```bash
# 安装（Mac）
brew install fzf

# 立即使用：交互式搜索当前目录所有文件
find . -type f | fzf

# 增强 Ctrl+R（历史命令搜索），加到 ~/.zshrc
source <(fzf --zsh)
```

💪 为什么比默认方式好
默认 `Ctrl+R` 只能逐条翻历史，fzf 让你边打字边模糊匹配，秒级定位。

🧪 数据科学场景
- **找实验脚本**：`find . -name "*.ipynb" | fzf` 快速打开某个 notebook
- **切 Git 分支**：`git branch | fzf | xargs git checkout` 不用记分支名
- **查历史命令**：`Ctrl+R` 输入 `train` 立刻找到上次的训练命令
