🎯 解决什么痛点
Git diff 默认输出混乱，难以快速定位代码变更，尤其对比大文件时眼睛累。

⚡ 快速上手
```bash
# 安装
brew install delta

# 配置 Git 使用 delta
git config --global core.pager "delta"
git config --global interactive.diffFilter "delta --color-only"
```

💪 为什么比默认方式好
默认 diff 只有单色文本，delta 提供语法高亮、行号、侧边栏，视觉体验直逼 VS Code 对比视图。

🧪 数据科学场景
审查 Jupyter Notebook 的 .ipynb 文件变更时，配合 `nbdime` 使用 delta 显示代码差异，一眼看出哪个 cell 改了参数或模型配置。
