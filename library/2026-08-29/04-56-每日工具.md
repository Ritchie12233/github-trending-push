🎯 解决什么痛点
数据集和模型文件越存越多，磁盘爆满时不知道哪些大文件该清理。

⚡ 快速上手
```bash
# macOS 安装
brew install ncdu

# 分析当前目录，进入交互界面
ncdu ~/data
# 按 d 删除选中文件，按 q 退出
```

💪 为什么比默认方式好
比 `du -sh *` 快且直观，支持交互式浏览和排序，不用逐层手动查找。

🧪 数据科学场景
训练完多个模型后，用 `ncdu ~/models` 快速定位哪些 checkpoint 占空间最大，一键清理旧版本，避免磁盘写满导致训练中断。
