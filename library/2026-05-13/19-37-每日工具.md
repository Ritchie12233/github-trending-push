🎯 解决什么痛点
数据集和日志文件不知不觉撑爆磁盘，用 `du -sh` 一个个查太慢，GUI 分析器又得开新窗口。

⚡ 快速上手
```bash
brew install ncdu          # 安装
ncdu ~/data                 # 扫描 data 目录，方向键浏览，d 删除，q 退出
```

💪 为什么比默认方式好
`du` 只能看单层，`ncdu` 交互式树状浏览 + 实时排序，一键定位最大文件。

🧪 数据科学场景
训练完模型发现磁盘满了，用 `ncdu ~/datasets` 秒杀缓存、重复下载的 CSV 和未压缩的 JSON，直接按 `d` 清理。
