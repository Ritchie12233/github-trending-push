🎯 解决什么痛点
数据集、日志、缓存文件不知不觉占满硬盘，用 `du -sh` 逐层查找太慢，GUI 工具又需要鼠标操作。

⚡ 快速上手
```bash
brew install ncdu   # 安装
ncdu ~/data         # 分析 data 目录，按方向键浏览，d 删除文件
```

💪 为什么比默认方式好
`du` 只能看单层大小，`ncdu` 交互式树状浏览 + 实时排序，一键定位最大文件夹。

🧪 数据科学场景
训练完模型发现磁盘爆满，用 `ncdu ~/datasets` 秒杀冗余的 `.csv` 备份和 `__pycache__`，释放空间。
