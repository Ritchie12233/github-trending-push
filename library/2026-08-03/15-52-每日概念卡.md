┃ 今天搞懂：什么是 API
┃ 板块：计算机系统
┗━━━━━━━━━━━━━━━━━━━━━━

💡 通俗理解
想象你去一家高级餐厅吃饭。你不会直接闯进厨房翻冰箱，而是拿起菜单，告诉服务员“我要一份椰浆饭”。服务员把你的需求传给厨房，再把做好的菜端给你。API 就是那个“服务员”——它规定了你能点什么菜（请求）、怎么点（格式），以及菜怎么端上来（响应）。你不需要知道厨房里怎么炒菜，只要会点菜就行。

🧠 核心要点
1. API 是“应用程序接口”的缩写，本质是两套软件之间沟通的“菜单和规则”。
2. 它定义了请求的格式（比如 URL、参数）和返回的数据结构（通常是 JSON），让不同系统能互相“听懂”。
3. 使用 API 时，你只关心“能做什么”，不关心“内部怎么实现”——这叫“封装”。
4. 常见的 API 类型包括 RESTful API（基于 HTTP 请求），是数据科学中最常用的。

📊 数据科学中的应用
当你做项目时，要获取天气数据、推特舆情或金融股价，你不需要自己爬网页或存数据库，直接用别人写好的 API 调用数据即可。比如用 `requests.get()` 从政府开放数据平台拉取马来西亚人口统计，返回 JSON 后直接转成 DataFrame 分析。

🔖 一句话记住
API 是软件世界的“服务员”——你点单，它上菜，不用管后厨怎么忙。
