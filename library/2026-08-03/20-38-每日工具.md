🎯 解决什么痛点
手动记录或安装依赖时版本混乱，换电脑或协作时环境无法复现。

⚡ 快速上手
```bash
# 导出当前环境所有包及版本
pip freeze > requirements.txt

# 在新环境一键安装
pip install -r requirements.txt
```

💪 为什么比默认方式好
比 `pip list` 更直接——输出即文件，且格式与 `pip install -r` 完全兼容，零转换成本。

🧪 数据科学场景
在 Kaggle 或 Colab 跑完实验后，导出环境提交到 GitHub，队友 `pip install -r` 即可复现你的 pandas/numpy/sklearn 版本，避免“在我电脑上能跑”的尴尬。
