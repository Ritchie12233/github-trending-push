🎯 解决什么痛点
用 `os.path` 拼接路径时总写 `os.path.join(a, b)`，且跨平台（Windows/Mac）路径分隔符不一致容易出错。

⚡ 快速上手
```python
from pathlib import Path

# 读取当前目录下 data/raw.csv
data = Path("data") / "raw.csv"
print(data.read_text())  # 直接读文件内容
```

💪 为什么比默认方式好
`pathlib` 用 `/` 运算符拼接路径，代码更直观；自动处理 Mac/Linux 的 `/` 和 Windows 的 `\`，无需手动转义。

🧪 数据科学场景

for csv_file in Path("data/raw").glob("*.csv"):
