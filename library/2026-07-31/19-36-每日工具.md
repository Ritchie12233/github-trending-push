🎯 解决什么痛点
每次敲 `ls -lah` 或 `git status` 这类长命令，手累心更累，还容易打错。

⚡ 快速上手
```bash
# 编辑 ~/.zshrc（Mac 默认用 zsh）
echo "alias ll='ls -lah'" >> ~/.zshrc
echo "alias gs='git status'" >> ~/.zshrc
source ~/.zshrc
# 以后直接输入 ll 或 gs 即可
```

💪 为什么比默认方式好
比敲完整命令快 3 倍，且可自定义组合，一次配置终身受益。

🧪 数据科学场景
- `alias jn='jupyter notebook'`：秒开 notebook，不用记路径
- `alias act='source venv/bin/activate'`：一键激活虚拟环境
- `alias df='df -h | grep -v tmpfs'`：快速看磁盘空间，防止训练时爆盘
