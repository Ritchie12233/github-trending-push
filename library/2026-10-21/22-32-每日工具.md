🎯 解决什么痛点
print() 输出 DataFrame 和长列表时挤成一团、看不清，调试和汇报都费劲。

⚡ 快速上手
```bash
pip install rich
```
```python
from rich import print
print({"model": "XGBoost", "auc": 0.91})  # 自动高亮、自动换行
```

💪 为什么比默认方式好
比 pprint 多了颜色、表格和进度条，一行 import 就能替换内置 print。

🧪 数据科学场景
训练循环里用 `Progress` 显示 epoch 进度，用 `Table` 把多组超参和指标并排打印，比手写格式化字符串省一半时间。
