🎯 解决什么痛点
每次都要敲 `ls -lah` 或 `cd ../../..`，重复劳动浪费时间。

⚡ 快速上手
```bash
# 在 ~/.zshrc 中添加（Mac 默认用 zsh）
echo "alias ll='ls -lah'" >> ~/.zshrc
echo "alias ..='cd ..'" >> ~/.zshrc
source ~/.zshrc
```

💪 为什么比默认方式好
把长命令缩成 2-3 个字符，每天省下几十次按键，肌肉记忆后零思考。

🧪 数据科学场景
- `alias jn='jupyter notebook'` — 快速启动 notebook
- `alias gs='git status'` — 频繁查看实验代码变更
- `alias act='source venv/bin/activate'` — 一键激活虚拟环境
