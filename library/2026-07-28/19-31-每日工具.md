🎯 解决什么痛点
不用在浏览器和编辑器之间切换，直接在 VS Code 里运行 .ipynb，还能实时查看变量值和交互图表。

⚡ 快速上手
1. 安装 Python 扩展（ms-python.python）
2. 打开 .ipynb 文件，点击“运行单元格” ▶️
3. 左侧“变量”面板自动显示所有变量类型、形状、值

💪 为什么比默认方式好
比 Jupyter Notebook 网页版快 3 倍启动，且变量浏览器比 `print()` 调试直观 10 倍。

🧪 数据科学场景
EDA 阶段：运行 `df.describe()` 后，变量面板直接显示 DataFrame 的列名、dtype、缺失值数量，不用反复 `df.info()`。
