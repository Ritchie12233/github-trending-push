🎯 解决什么痛点
SSH 一断，跑了几小时的模型训练直接归零；想同时看日志、跑代码、开 Python 只能疯狂切窗口。

⚡ 快速上手
```bash
brew install tmux          # Mac 安装
tmux new -s train          # 新建名为 train 的会话
# 断线后重连：
tmux attach -t train
```
常用快捷键（先按 `Ctrl+b` 再按）：`%` 左右分屏，`"` 上下分屏，`d` 挂起会话。

💪 为什么比默认方式好
比开多个终端窗口更省资源，且会话与 SSH 解耦——关掉电脑任务照跑。

🧪 数据科学场景
在马来亚大学服务器上跑 `model.fit()` 或大数据预处理时，用 tmux 挂起后安心合盖走人；回来 `attach` 一看，训练早跑完了，日志和结果都在。
