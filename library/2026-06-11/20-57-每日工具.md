🎯 解决什么痛点
在大量数据文件、日志或代码中快速定位文件，避免手动翻找或等待缓慢的 find 命令。

⚡ 快速上手
```bash
# 安装
brew install fd

# 在当前目录搜索所有 .csv 文件
fd .csv

# 搜索文件名包含 "sales" 的文件（忽略大小写）
fd -i sales

# 搜索特定目录下的 .json 文件
fd .json /Users/yourname/data
```

💪 为什么比默认方式好
`find . -name "*.csv"` 慢且语法繁琐；`fd` 默认支持正则、智能大小写、忽略 .gitignore，速度是 find 的 5-10 倍。

🧪 数据科学场景
在 `~/data` 目录下有 10 万+ 个实验日志和 CSV 文件，用 `fd 2026_06 .` 秒出结果，配合 `xargs` 批量处理文件：`fd .csv | xargs -I {} python clean.py {}`
