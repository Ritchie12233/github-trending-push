**1. 从零实现大模型（LLMs-from-scratch）**
- 🔗 https://github.com/rasbt/LLMs-from-scratch
- ⭐ 105,900 | 🍴 16,286 | 语言：Jupyter Notebook
- 📝 简介：用 PyTorch 从零开始、一步一步实现一个类似 ChatGPT 的大语言模型。涵盖注意力机制、分词器、预训练、指令微调等完整流程。
- 💡 推荐理由：作为数据科学研究生，理解 LLM 的底层原理是当前最核心的竞争力之一。这个项目不是"调包教程"，而是真正带你从矩阵运算开始构建 Transformer，非常适合作为深度学习课程的补充实践。每个章节都有配套 Notebook，可以直接在 Colab 上运行。
- 🎯 适用场景：深度学习课程项目、论文中的模型原理理解、面试准备中的 LLM 基础问答。

- 🔗 https://github.com/microsoft/markitdown
- ⭐ 188,063 | 🍴 13,916 | 语言：Python
- 📝 简介：微软出品的 Python 工具，可将 PDF、Word、Excel、PPT 等办公文档转换为 Markdown 格式。

- 📝 简介：将代码库、文档、SQL Schema、PDF 等转化为可查询的知识图谱，基于 AST 解析，无需向量数据库。

📊 本周趋势观察
本周开源社区最显著的趋势是 **AI Agent 工具链的全面爆发**——从 Agent 框架（openclaw、hermes-agent）、Agent 技能系统（ECC、superpowers）到 Agent 专用工具（browser-use、graphify），整个生态正在快速分化与成熟。与此同时，**数据科学基础设施持续迭代**，pandas、scikit-learn、Airflow 等核心库保持高频更新，说明数据工程仍是刚需。另一个值得注意的动向是 **"从零构建"类教育项目热度不减**（LLMs-from-scratch、ai-engineering-from-scratch），反映出开发者对底层原理的渴求。最后，**知识图谱与 RAG 的融合**（graphify）正在成为新的研究热点。

📖 学习建议
1. **先打地基再追热点**：本周 Agent 类项目很多，但如果你的 Python 和机器学习基础还不够扎实，建议先用「30天Python挑战」和「机器学习公开课」补齐基础，再回头研究 Agent 框架。否则很容易变成"只会调 API"。
2. **选一个方向做深**：数据科学范围很广，建议从本周项目中选一个与你研究方向最相关的深入实践——比如做 NLP 方向就跟着「从零实现大模型」走一遍完整流程，做金融方向就用「开源数据平台」跑一个完整的数据分析项目。一个深入的项目经验远比收藏十个仓库更有价值。
