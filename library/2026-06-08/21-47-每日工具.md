🎯 解决什么痛点
代码风格检查+格式化太慢，且需要装 flake8、black、isort 三个工具，配置繁琐。

⚡ 快速上手
```bash
# 安装
pip install ruff

# 检查当前目录所有 .py 文件
ruff check .

# 自动修复 + 格式化（一步到位）
ruff check --fix . && ruff format .
```

💪 为什么比默认方式好
速度比 flake8+black+isort 快 10-100 倍，且一个工具覆盖三个功能，零配置即可运行。

🧪 数据科学场景
在 Jupyter Notebook 导出 .py 后，或多人协作的 Kaggle/论文代码仓库中，用 `ruff check --fix .` 一键统一代码风格，避免 review 时因缩进、引号、import 顺序争吵。
