🎯 解决什么痛点
在几十个 notebook、脚本和数据集目录里找“那段代码到底写在哪个文件”，用 grep 又慢又会被 .git、缓存文件刷屏。

⚡ 快速上手
```bash
brew install ripgrep

# 在当前项目里找所有用到 pandas.read_csv 的地方（带行号）
rg -n "read_csv"

# 只搜 Python 文件，忽略大小写
rg -n -i -t py "missing_values"
```

💪 为什么比默认方式好
自动跳过 .gitignore 和二进制文件，多线程搜索，通常比 grep 快 5–10 倍且结果更干净。

🧪 数据科学场景
接手别人的项目或翻自己半年前的作业时，快速定位某个函数、列名、路径写在哪个 .py / .ipynb 里，不用一个个打开文件找。
