🎯 解决什么痛点
不用写 Python 脚本，终端直接解析、过滤、格式化 JSON 数据，尤其适合调试 API 返回结果。

⚡ 快速上手
```bash
# 安装
brew install jq

# 从 API 获取数据并提取特定字段
curl -s https://api.github.com/repos/jqlang/jq | jq '.description, .stargazers_count'
```

💪 为什么比默认方式好
`cat data.json | python -m json.tool` 只能格式化，jq 还能过滤、映射、聚合，一行搞定复杂查询。

🧪 数据科学场景
调试 Kaggle/OpenML 数据集 API 时，快速查看 JSON 结构并提取关键字段，避免每次写 Python 脚本。
