**1. 从零实现大模型 — 手写 ChatGPT 级 LLM 教程（⭐106k）**
- **项目**：rasbt/LLMs-from-scratch
- **语言**：Jupyter Notebook | **Topics**：llm, pytorch, transformers, from-scratch
- **亮点**：用 PyTorch 从零一步步实现一个类 ChatGPT 的大语言模型，涵盖注意力机制、分词器、预训练、指令微调全流程。代码即教程，每个概念都有可运行的 Notebook。
- **研究生用法**：这是理解 Transformer 内部机制的最佳路径。做 NLP 或 LLM 相关研究时，与其调包，不如先跑通这个项目——你会真正理解 attention、tokenizer、fine-tuning 的每一个细节，写论文时方法论部分不再心虚。
- **推荐理由**：数据科学研究生绕不开 LLM，但大多数人只会调 API。这个项目让你从"使用者"变成"理解者"，是做 LLM 研究的最低门槛。

**2. 智能体技能框架 — 让 AI 真正干活的开发方法论（⭐297k）**
- **项目**：obra/superpowers
- **语言**：Shell | **Topics**：ai, skills, subagent-driven-development, sdlc
- **亮点**：一套 Agent 技能框架 + 软件开发方法论，核心理念是"子智能体驱动开发"——把复杂任务拆解给多个专职 Agent 协作完成。本周 star 增长最快的项目之一。
- **研究生用法**：如果你在做多智能体系统、自动化研究流程（如自动文献综述、自动实验设计），这套框架提供了可复用的设计模式。可以直接借鉴其"技能拆分"思路来设计你的研究 Agent。
- **推荐理由**：Agent 是当前 AI 研究最热的方向，这个项目代表了"Agent 工程化"的最新实践，比单纯读论文更有体感。

**3. 代码知识图谱 — 把代码库变成可查询图谱（⭐125k）**
- **项目**：Graphify-Labs/graphify
- **语言**：Python | **Topics**：knowledge-graph, graphrag, ast, rag, code-analysis
- **亮点**：将任意代码库（含文档、SQL schema、配置文件、PDF）转化为可查询的知识图谱。本地确定性 AST 解析，每条边都有解释，不依赖向量数据库。
- **研究生用法**：这是 GraphRAG 在代码领域的绝佳实践案例。如果你的研究涉及知识图谱构建、RAG 优化、或代码理解，这个项目提供了完整的工程参考。也可以用它来管理你自己的研究代码库。
- **推荐理由**：知识图谱 + RAG 是数据科学的前沿交叉点，这个项目把两者结合得非常漂亮，且完全开源可复现。

**4. 网页数据抓取 — 为 AI 智能体提供网络数据（⭐190k）**
- **项目**：firecrawl/firecrawl
- **语言**：TypeScript | **Topics**：web-scraping, ai-agents, data-extraction, llm
- **亮点**：专为 AI Agent 设计的网页抓取工具，能把任意网页转成干净的 Markdown 或结构化数据，直接喂给 LLM。支持爬取、搜索、数据提取。
- **研究生用法**：做数据采集、构建领域数据集、或给 RAG 系统补充实时网络数据时非常实用。比手写爬虫省 80% 的时间。
- **推荐理由**：数据科学研究的起点往往是"搞数据"，这个工具能显著加速你的数据获取环节。

**5. 文档转 Markdown — 办公文件一键转结构化文本（⭐189k）**
- **项目**：microsoft/markitdown

- **亮点**：微软出品，把 PDF、Word、Excel、PPT 等办公文档一键转成 Markdown。与 LangChain、AutoGen 生态无缝集成。
- **研究生用法**：处理论文 PDF、课程资料、政府报告等非结构化数据时的利器。转成 Markdown 后可以直接做文本分析或喂给 LLM。
- **推荐理由**：数据清洗是数据科学最耗时的环节，这个工具专治"格式地狱"。

📊 本周趋势观察
本周开源社区最显著的趋势是 **AI Agent 从"对话"走向"干活"**——superpowers、ECC、hermes-agent 等技能框架密集涌现，Agent 工程化正在成为独立赛道。其次，**RAG 与知识图谱的融合加速**，graphify 用确定性 AST 解析替代向量库，代表了"可解释 RAG"的新方向。第三，**数据科学基础设施持续完善**，firecrawl、markitdown 等工具让非结构化数据处理变得前所未有的简单。最后，传统学习资源（freeCodeCamp、free-programming-books）依然稳居 star 榜前列，说明社区对"基础扎实"的追求从未改变。

📖 学习建议
1. **先跑通"从零实现大模型"，再碰 Agent 框架**：很多同学一上来就想做 Agent，但如果不理解 LLM 的底层机制（attention、tokenizer、fine-tuning），设计出来的 Agent 只是"调 API 的壳"。建议用 2-3 周跑完 rasbt 的教程，再回头看 superpowers 的设计理念，你会有完全不同的理解。
2. **用"项目式学习"补齐工程能力，而非刷课**：非 CS 背景的研究生最容易陷入"看教程→感觉懂了→实际不会"的循环。建议从 project-based-learning 中挑一个与你研究相关的小项目（如"用 Streamlit 做一个数据探索工具"），强迫自己从零完成，遇到问题再查文档。这种"做中学"的效率是看视频的 5 倍以上。
