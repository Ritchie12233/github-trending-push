🎯 解决什么痛点
在本地 Mac 上写代码，却要跑在实验室/云端的 Linux 服务器上，来回 scp 传文件、终端里用 vim 改代码，效率极低。

⚡ 快速上手
1. VS Code 扩展市场搜索安装 `Remote - SSH`（微软官方）
2. 按 `Cmd+Shift+P` → 输入 `Remote-SSH: Connect to Host` → 填 `用户名@服务器IP`
3. 连上后 `File > Open Folder` 打开远程目录，之后就像编辑本地文件一样

💪 为什么比默认方式好
不用 scp 同步、不用 vim，本地界面 + 远程算力，代码和数据始终在服务器上。

🧪 数据科学场景
你的数据集和 GPU 都在服务器上，用 Remote SSH 直接在服务器环境里跑 Jupyter/Python，本地 Mac 只当"显示器"，训练大模型时笔记本风扇都不转。
