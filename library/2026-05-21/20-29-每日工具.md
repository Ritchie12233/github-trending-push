🎯 解决什么痛点
正在改代码时突然要切分支修bug，但改动还没完成不想提交，又怕丢失。

⚡ 快速上手
```bash
# 临时保存当前修改（工作区变干净）
git stash

# 切分支修完bug后，回来恢复
git stash pop
```

💪 为什么比默认方式好
比 `git commit --amend` 或新建临时分支更轻量，无需产生垃圾提交记录。

🧪 数据科学场景
跑完EDA发现需要紧急修复另一个分支的模型参数，`git stash` 保存当前notebook改动，切过去修完再 `pop` 回来继续分析。
