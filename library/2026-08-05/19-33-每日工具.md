🎯 解决什么痛点
写代码或看数据时，随手算个均值、标准差，不用切窗口打开计算器 App，打断思路。

⚡ 快速上手
按 `Cmd + Space`，直接输入：
```
(3.5 + 4.2 + 2.8) / 3
sqrt(144)
log10(1000)
```
回车即得结果，支持四则运算、括号、平方根、对数等。

💪 为什么比默认方式好
比打开计算器 App 快 3 秒，且支持自然算式输入，不用点按钮；比 Python REPL 更轻量，不离开当前窗口。

🧪 数据科学场景
快速验证特征缩放后的数值范围、计算 batch 大小或学习率调整的中间值，或核对论文里的统计量，不用开 Jupyter。
