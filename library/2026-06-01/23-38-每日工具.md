🎯 解决什么痛点
重复调用相同参数的函数时，每次都重新计算，浪费时间和算力。

⚡ 快速上手
```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fibonacci(n):
    return n if n < 2 else fibonacci(n-1) + fibonacci(n-2)

# 首次计算 fibonacci(50) 会慢，之后调用瞬间返回
```

💪 为什么比默认方式好
无需手动写字典存结果，一行装饰器自动管理缓存，且支持最大缓存数限制，内存可控。

🧪 数据科学场景
在特征工程中，对同一组参数反复调用复杂的数据清洗函数（如正则解析、API查询）时，直接缓存结果，避免重复计算，尤其适合循环调参或交叉验证。
