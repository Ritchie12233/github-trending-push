🎯 解决什么痛点
SSH 一断，训练就断——tmux 让任务在后台持续运行，还能分屏操作。

⚡ 快速上手
```bash
# 安装
brew install tmux

# 新建会话（跑训练）
tmux new -s train

# 分离（关掉终端也不怕）
Ctrl-b d

# 重新连回
tmux attach -t train
```

💪 为什么比默认方式好
`nohup` 只能后台跑，tmux 还能随时查看进度、分屏调试，比 `screen` 更现代。

🧪 数据科学场景
跑 3 小时模型训练时，直接关电脑走人，回来 `tmux attach` 看结果；分屏左边看日志、右边写代码。
