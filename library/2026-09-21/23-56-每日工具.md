🎯 解决什么痛点
用 requests 抓数据时，几百个 API 只能一个个排队等，慢到怀疑人生。

⚡ 快速上手
```bash
pip install httpx
```
```python
import httpx, asyncio

async def fetch(url):
    async with httpx.AsyncClient() as client:
        return (await client.get(url)).json()

# 并发抓 100 个 URL
results = await asyncio.gather(*[fetch(u) for u in urls])
```

💪 为什么比默认方式好
requests 是同步阻塞的，httpx 原生支持 async，同样的代码并发快 10 倍以上。

🧪 数据科学场景
批量调用 API 拉数据（如 Twitter、Kaggle、政府开放数据）时，用 `asyncio.gather` 并发请求，几分钟的活几秒搞定；配合 `timeout` 和 `retries` 参数，爬虫稳定性也更好。
