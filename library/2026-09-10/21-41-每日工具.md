🎯 解决什么痛点
临时算个数还要切窗口、开计算器 App，打断写代码的思路。

⚡ 快速上手
按 `Cmd + Space` 唤出 Spotlight，直接输入算式回车即可：

```
(1200 * 0.15) + 88
```

💪 为什么比默认方式好
不用离开键盘、不用切换 App，比打开"计算器"快 5 秒以上。

🧪 数据科学场景
快速估算样本量、学习率、损失值或百分比（如 `0.8 * 0.9`），验证模型输出时随手一算，不打断 Python 调试节奏。
