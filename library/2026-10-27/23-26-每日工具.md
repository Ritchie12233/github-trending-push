🎯 解决什么痛点
写完的数据脚本每次都要改代码里的参数，想做成命令行工具又嫌 argparse 太啰嗦。

⚡ 快速上手
```bash
pip install typer
```
```python
import typer
app = typer.Typer()

@app.command()
def train(data: str, epochs: int = 10, lr: float = 0.001):
    print(f"训练 {data}，{epochs} 轮，学习率 {lr}")

if __name__ == "__main__":
    app()
```
运行：`python train.py data.csv --epochs 50 --lr 0.01`

💪 为什么比默认方式好
比 argparse 少写 70% 样板代码，类型注解自动转成参数校验和 `--help` 文档。

🧪 数据科学场景
把 `clean.py`、`train.py`、`evaluate.py` 这类脚本包成带参数的命令行工具，换数据集或调超参时不用打开编辑器改代码，直接在终端跑；配合 `--help` 还能当自己的使用说明书。
