🎯 解决什么痛点
requests 不支持 async，批量抓取 API 数据时只能串行等待，慢得让人抓狂。

⚡ 快速上手
```bash
pip install httpx
```
```python
import httpx
r = httpx.get("https://api.example.com/data", timeout=10)
print(r.json())
```

💪 为什么比默认方式好
API 与 requests 几乎一致，却原生支持 async/await 和 HTTP/2，迁移成本近乎为零。

🧪 数据科学场景
并发拉取多个数据源（如批量调用公开 API、爬取分页接口）时，用 `httpx.AsyncClient` + `asyncio.gather` 把几十个请求同时发出，抓数据时间从几分钟缩到几秒。
