🎯 解决什么痛点
训练模型或处理大数据时，循环跑半天不知道进度，无法预估剩余时间。

⚡ 快速上手
```python
from tqdm import tqdm
for i in tqdm(range(100)):
    time.sleep(0.1)  # 模拟耗时操作
```

💪 为什么比默认方式好
自带ETA、速度、进度百分比，无需手动print，一行代码替换range即可。

🧪 数据科学场景
训练深度学习模型时，用`tqdm(train_loader)`包装DataLoader，实时监控每个epoch的batch进度和剩余时间。
