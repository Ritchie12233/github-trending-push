🎯 解决什么痛点
写论文/README 时，画流程图要切到 draw.io 或 PPT，改一次图就要重新截图，版本管理混乱。

⚡ 快速上手
```markdown
```mermaid
graph LR
    A[原始数据] --> B[清洗]
    B --> C[特征工程]
    C --> D[模型训练]
    D --> E[评估]
```
```
直接粘贴到 GitHub 或 Typora（需开启 Mermaid 支持）即可渲染。

💪 为什么比默认方式好
纯文本即图表，Git 可 diff，改逻辑只需改几行字，不用重画。

🧪 数据科学场景
写实验报告时，用时序图展示数据流水线（采集→预处理→训练→部署）的先后依赖，或画模型对比的决策树流程，评审时一眼看懂。
