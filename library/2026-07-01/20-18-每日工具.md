🎯 解决什么痛点
抓取网页数据时，不知道后端 API 返回了什么，写 Python 请求前要反复猜参数和 headers。

⚡ 快速上手
1. 打开网页 → F12 → 点「Network」标签
2. 刷新页面，找到目标请求（如 .json / .csv）
3. 右键请求 → Copy → Copy as cURL
4. 终端粘贴，加 `| python -m json.tool` 格式化输出

💪 为什么比默认方式好
不用装 Postman 或写 Python 脚本，30 秒验证 API 是否可用，headers 和 cookies 自动带齐。

🧪 数据科学场景
抓取政府开放数据（如 data.gov.my）的 JSON 接口，复制 cURL 后直接转为 `requests.get(url, headers=...)` 代码，省去手动构造 headers 的试错时间。
