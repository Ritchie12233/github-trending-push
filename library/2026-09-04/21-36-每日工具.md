🎯 解决什么痛点
不用再把代码拷来拷去，直接在本地编辑器里写服务器上的代码，调试和运行都在远程。

⚡ 快速上手
```bash
# 安装 Remote-SSH 扩展后，在 VS Code 中按 Cmd+Shift+P
# 输入 "Remote-SSH: Connect to Host"，填入你的服务器地址
ssh user@your_server_ip
```

💪 为什么比默认方式好
比 Jupyter Notebook 或 vim 更流畅，本地体验 + 远程算力，不用同步文件。

🧪 数据科学场景
在 Mac 上写代码，跑在实验室 GPU 服务器上。比如训练模型时，直接本地改 `train.py`，远程跑 `python train.py`，日志实时回传，不用来回 scp。
