🎯 解决什么痛点
数据从外部（API、CSV、数据库）进来时，类型混乱、字段缺失，代码里到处是 if 判断和 try-except，pydantic 用声明式模型自动校验和转换。

⚡ 快速上手
```bash
pip install pydantic
```
```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

user = User(name="Alice", age="25")  # age 自动转成 int
print(user.age)  # 25
```

💪 为什么比默认方式好
比手写 `isinstance` + `dict.get` 更简洁，报错信息清晰，且性能比 dataclass 快。

🧪 数据科学场景
读取 Kaggle 数据集或爬虫结果时，用 pydantic 定义 schema，一行代码过滤脏数据，避免后续建模时因类型错误崩溃。
