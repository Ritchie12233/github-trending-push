🎯 解决什么痛点
Git diff 输出杂乱无章，难以快速定位代码变更。

⚡ 快速上手
```bash
# 安装
brew install git-delta
# 配置到 ~/.gitconfig
[core]
    pager = delta
[interactive]
    diffFilter = delta --color-only
```

💪 为什么比默认方式好
默认 diff 只有单调的 +/- 标记，delta 提供行内高亮、语法着色和侧边栏，一眼看清改动。

🧪 数据科学场景
审查 Jupyter Notebook 的 .ipynb 文件变更时，配合 `nbdime` 使用 delta，能清晰看到代码和输出变化，避免漏改关键逻辑。
