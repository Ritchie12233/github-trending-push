🎯 解决什么痛点
不用再手写 `__init__`、`__repr__`、`__eq__` 等样板代码，定义数据容器只需声明字段。

⚡ 快速上手
```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    gpa: float
    year: int = 1

s = Student("Alice", 3.8)  # 自动生成 __init__
print(s)                   # 自动生成 __repr__
```

💪 为什么比默认方式好
比手写 class 省 5-10 行代码，比 dict 有类型提示和 IDE 自动补全。

🧪 数据科学场景
定义模型训练配置（超参数、路径、标签映射），比 dict 更安全、比手写 class 更省事。
