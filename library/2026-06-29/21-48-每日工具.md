🎯 解决什么痛点
不用离开 notebook 就能测代码性能、保存文件、回溯历史，省去反复切终端的时间。

⚡ 快速上手
```python
# 测性能：比较列表推导和 for 循环
%timeit [x**2 for x in range(1000)]

# 保存当前 cell 为 Python 脚本
%%writefile my_script.py
def hello():
    print("Hello, DS!")

# 查看最近 5 条命令历史
%history -n 1-5
```

💪 为什么比默认方式好
比 `time.time()` 手动计时更精准（自动多次运行取均值），比复制粘贴到编辑器更省事。

🧪 数据科学场景
- 调参时用 `%timeit` 快速对比不同向量化方法的性能
- 用 `%%writefile` 把清洗好的数据预处理代码一键导出为 `.py` 文件
- 用 `%history` 找回之前跑过的复杂查询或可视化代码
