🎯 解决什么痛点
不用再开浏览器切 Jupyter Tab，在 VS Code 里直接跑 cell、看变量和图表，调试和写代码零切换。

⚡ 快速上手
```bash
# 安装 VS Code 后，装 Python 扩展即可
code --install-extension ms-python.python
# 打开 .ipynb 文件，选好 kernel，直接 Shift+Enter 跑 cell
```

💪 为什么比默认方式好
比浏览器版 Jupyter 多了原生调试器（断点+变量实时跟踪），且和项目代码、Git 在同一窗口，省去来回切换。

🧪 数据科学场景
跑 EDA 时，用变量浏览器实时检查 DataFrame 的 shape/dtypes，配合 `%matplotlib inline` 交互缩放图表，快速定位缺失值分布，不用反复 print 头几行。
