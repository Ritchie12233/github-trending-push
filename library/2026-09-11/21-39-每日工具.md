🎯 解决什么痛点
爬虫/调 API 时不知道请求头、参数、Cookie 长啥样，靠猜和试错浪费大量时间。

⚡ 快速上手
1. Chrome 打开目标网页 → 按 `F12` → 切到 **Network** 面板
2. 刷新页面，点任意请求 → 右键 → **Copy → Copy as cURL**
3. 粘贴到终端，把 `curl` 换成 `curlconverter` 或直接转 Python：

```bash
# 方式一：直接跑（验证请求）
curl 'https://api.example.com/data' -H 'Authorization: Bearer xxx'

# 方式二：转成 Python requests 代码
pip install curlconverter
curlconverter --language python < 粘贴的cURL
```

💪 为什么比默认方式好
比手动翻文档、猜 header 快 10 倍，一次复制拿到完整可复现请求。

🧪 数据科学场景
抓取马来亚大学课程/图书馆/学术 API 数据前，先用 Network 面板摸清真实请求结构，再写 `requests` 或 `httpx` 脚本，避免 403/参数错误。
