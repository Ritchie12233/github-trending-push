🎯 解决什么痛点
每次写 `import pandas as pd` + 读CSV + 查看基本信息，都要重复敲十几行模板代码，浪费时间且容易打错。

⚡ 快速上手
在 VS Code 中按 `Cmd+Shift+P` → 输入 “Configure User Snippets” → 选择 `python.json`，粘贴：
```json
{
  "Pandas Quick Load": {
    "prefix": "pdload",
    "body": [
      "import pandas as pd",
      "import numpy as np",
      "",
      "df = pd.read_csv('$1.csv')",
      "print(df.head())",
      "print(df.info())",
      "$0"
    ],
    "description": "快速加载CSV并预览"
  }
}
```
保存后，在 `.py` 文件中输入 `pdload` 再按 `Tab`，模板自动展开。

💪 为什么比默认方式好
比 Copilot 生成更可控——模板完全由你定义，不依赖网络，且触发词短、展开即时，适合高频固定操作。

🧪 数据科学场景
最适合 **EDA（探索性数据分析）** 起步：一键生成“加载数据→查看形状→检查缺失值→描述统计”的标准开头；也可为 `train_test_split`、`matplotlib 绘图样式` 等常用流程建专属片段，让每次建模前的重复劳动降到零。
