🎯 解决什么痛点
实验代码写到一半，突然要切分支修 bug，不想 commit 半成品。

⚡ 快速上手
```bash
git stash -u          # 暂存所有修改（含未跟踪文件）
git stash pop         # 恢复最近一次暂存
```

💪 为什么比默认方式好
比 `git commit -m "wip"` 干净，不会污染提交历史，且支持多个 stash 栈。

🧪 数据科学场景
调参跑实验时，导师突然让改数据预处理逻辑。`git stash -u` 保存当前 notebook 和代码，切分支改完回来 `git stash pop` 继续跑，零中断。
