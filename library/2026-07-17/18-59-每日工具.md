🎯 解决什么痛点
在成千上万个数据文件中快速定位目标文件，避免手动翻找或等待缓慢的 find 命令。

⚡ 快速上手
```bash
# 安装
brew install fd

# 在当前目录递归搜索所有 .csv 文件
fd .csv

# 搜索名称包含 "sales" 的 .parquet 文件
fd sales -e parquet
```

💪 为什么比默认方式好
`find . -name "*.csv"` 语法繁琐且慢；`fd` 默认忽略隐藏文件和 .gitignore，搜索速度是 find 的 5-10 倍。

🧪 数据科学场景
在包含数百个 CSV、Parquet、JSON 文件的实验目录中，`fd sales_2026 -e csv` 瞬间定位到目标文件，配合 `cat` 或 `head` 直接预览内容。
