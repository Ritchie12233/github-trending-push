🎯 解决什么痛点
不用打开 Draw.io 或 Figma，在 Markdown 里直接写代码就能生成可维护的图表。

⚡ 快速上手
在 GitHub 或支持 Mermaid 的 Markdown 编辑器中，直接写：
```mermaid
graph LR
A[原始数据] --> B[清洗]
B --> C[建模]
C --> D[评估]
```

💪 为什么比默认方式好
无需截图/上传，图表随代码版本控制，修改只需改几行文本。

🧪 数据科学场景
在项目 README 中画 ETL 流程图、模型训练 pipeline 或实验对比时序图，队友直接看代码就能理解流程。
