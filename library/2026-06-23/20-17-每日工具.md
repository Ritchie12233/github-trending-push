🎯 解决什么痛点
每次写数据加载、EDA、模型训练都要重复敲同样的样板代码，浪费时间且容易出错。

⚡ 快速上手
在 VS Code 中按 `Cmd+Shift+P` → 输入“Snippets: Configure User Snippets” → 选择 `python.json`，粘贴：
```json
"Load CSV": {
  "prefix": "lcsv",
  "body": [
    "import pandas as pd",
    "df = pd.read_csv('${1:path/to/file.csv}')",
    "print(df.head())",
    "print(df.info())"
  ],
  "description": "快速加载CSV并预览"
}
```
之后在 `.py` 文件中输入 `lcsv` + `Tab` 即可展开。

💪 为什么比默认方式好
比手动复制粘贴快3倍，且模板可自定义变量（如 `${1:path}`），一键填充路径。

🧪 数据科学场景
写 EDA 脚本时，输入 `lcsv` 秒出加载代码，再配合 `ldesc`（描述统计）、`lmiss`（缺失值检查）等片段，10分钟搭完分析框架。
