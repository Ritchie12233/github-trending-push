🎯 解决什么痛点
重复调用相同参数的函数时，每次都重新计算，浪费时间和算力。

⚡ 快速上手
```python
from functools import lru_cache

@lru_cache(maxsize=128)
def expensive_func(x):
    # 模拟耗时计算
    return x ** 2 + sum(range(x))
```

💪 为什么比默认方式好
一行装饰器自动缓存，无需手动维护字典，且内置 LRU 淘汰策略，内存可控。

🧪 数据科学场景
特征工程中反复调用预处理函数（如文本清洗、数值变换）时，缓存相同输入的结果，大幅加速交叉验证和网格搜索中的重复计算。
