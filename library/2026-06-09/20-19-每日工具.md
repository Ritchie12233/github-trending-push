🎯 解决什么痛点
API 返回的 JSON 数据又长又乱，肉眼找字段太慢，用 Python 解析又得写好几行代码。

⚡ 快速上手
```bash
# 安装
brew install jq

# 从 API 直接提取字段（以 GitHub API 为例）
curl -s https://api.github.com/repos/jqlang/jq | jq '.description'
```

💪 为什么比默认方式好
`cat data.json | python -c "import json,sys; print(json.load(sys.stdin)['key'])"` 写 3 行，jq 只需 1 行。

🧪 数据科学场景
从 Kaggle 或 Open Data API 拉取 JSON 格式数据集时，先用 `jq '.data | length'` 看记录数，再用 `jq '.data[0:5]'` 预览前 5 条，比下载后打开快 10 倍。
