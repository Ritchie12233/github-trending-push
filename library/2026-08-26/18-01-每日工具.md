🎯 解决什么痛点
不用再记或敲一长串项目路径，输入几个关键词就能跳到最常去的目录。

⚡ 快速上手
```bash
# 安装（macOS）
brew install zoxide

# 在 ~/.zshrc 中添加（Mac 默认 zsh）
eval "$(zoxide init zsh)"

# 使用：跳转到最常访问的 data 相关目录
z data
```

💪 为什么比默认方式好
`cd` 需要完整路径，`z` 只需模糊关键词，且自动按使用频率排序。

🧪 数据科学场景
每天在 `~/projects/um-masters/`、`~/datasets/kaggle/`、`~/notebooks/` 之间切换，`z kaggle` 一键直达，省去反复 `cd ../../..` 的麻烦。
