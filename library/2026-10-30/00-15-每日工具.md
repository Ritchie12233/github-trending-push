🎯 解决什么痛点
写完 notebook 或脚本后，代码风格乱、import 顺序乱、还有未使用变量，手动整理又慢又容易漏。

⚡ 快速上手
```bash
pip install ruff
ruff check --fix .   # 自动修 lint 问题
ruff format .        # 格式化代码
```

💪 为什么比默认方式好
一个工具替代 flake8+black+isort，速度快 10–100 倍，配置只需一个 `pyproject.toml`。

🧪 数据科学场景
把 `.py` 脚本或导出的 notebook 代码一键整理干净，交作业、push GitHub、给导师看代码前跑一遍，风格统一又专业。
