🎯 解决什么痛点
API 返回的 JSON 数据又长又乱，肉眼找字段费时费力，jq 让你在终端秒级提取、过滤、格式化 JSON。

⚡ 快速上手
```bash
# 安装（Mac）
brew install jq

# 实战：提取 API 响应中的特定字段
curl -s https://api.github.com/repos/jqlang/jq | jq '.stargazers_count, .description'

# 进阶：过滤数组（如取评分 > 4.5 的电影）
cat movies.json | jq '.[] | select(.rating > 4.5) | {title, rating}'
```

💪 为什么比默认方式好
Python 写脚本解析要 5 行代码，jq 一行搞定，且无需打开编辑器，管道直接处理流式数据。

🧪 数据科学场景
快速检查 Kaggle 数据集 JSON 结构、调试爬虫返回结果、从 REST API 批量抽取特征字段，省去反复写 `json.load()` 的调试时间。
