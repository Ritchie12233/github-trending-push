🎯 解决什么痛点
在几十个 .py 和 .csv 文件里找某个变量名或报错信息时，grep 又慢又爱翻出一堆无关文件。

⚡ 快速上手
```bash
brew install ripgrep          # Mac 一行装好
rg "missing_values" --type py # 只在 Python 文件里搜
rg "NaN" -C 2                 # 显示匹配行上下各 2 行
```

💪 为什么比默认方式好
比 grep 快一个数量级，且默认跳过 .git、node_modules 和二进制文件，不用手动排除。

🧪 数据科学场景
调试 notebook 报错时，用 `rg "KeyError" -C 3` 秒定位是哪个脚本、哪一行触发的；或在项目里搜某个特征列名 `rg "user_id"`，立刻知道哪些 .py 文件在读它。
