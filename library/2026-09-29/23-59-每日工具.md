🎯 解决什么痛点
SSH 一断，跑了 3 小时的模型训练全没了；想同时看日志、跑代码、开 Python，却要开一堆终端窗口。

⚡ 快速上手
```bash
brew install tmux          # Mac 安装
tmux new -s train          # 新建名为 train 的会话
# 断线后重连：tmux attach -t train
```
分屏快捷键（先按 `Ctrl+b` 再按）：`%` 左右分屏，`"` 上下分屏，方向键切换。

💪 为什么比默认方式好
比直接开多个终端窗口更省资源，且会话在后台独立存活，断网、关窗口都不影响任务。

🧪 数据科学场景
在马来亚大学服务器上跑 `python train.py` 训练模型，用 tmux 挂后台，笔记本合盖回宿舍再 `attach` 回来，训练照跑、日志照看，还能一个窗口分屏同时盯 loss 和写代码。
