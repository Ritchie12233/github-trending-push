🎯 解决什么痛点
抓取网页数据时，不用读晦涩的 JS 源码，直接看浏览器发出的 API 请求，一键复制成 cURL 命令就能在终端复现和调试。

⚡ 快速上手
1. 打开目标网页 → 按 `F12` → 切到 **Network** 面板
2. 刷新页面，找到感兴趣的请求（如 `data.json`）
3. 右键 → **Copy as cURL** → 粘贴到终端执行：
```bash
curl 'https://api.example.com/data' -H 'User-Agent: ...' --compressed
```
（若需 Python 格式，可复制后粘贴到 [curlconverter.com](https://curlconverter.com) 自动转换）

💪 为什么比默认方式好
比 `requests.get()` 手写 headers 快 10 倍，自动带上 Cookie、Token 等认证信息，避免 403 错误。

🧪 数据科学场景
爬取 Kaggle 竞赛或公开数据集时，用 cURL 直接下载文件；或分析网页背后真实的数据接口，绕过 HTML 解析，直接拿 JSON 做 pandas 分析。
