🎯 解决什么痛点
SSH 断线或合盖休眠后，正在跑的 Python 训练/爬虫任务不会被杀掉，回来还能接着看输出。

⚡ 快速上手
```bash
brew install tmux                 # 安装
tmux new -s train                 # 新建名为 train 的会话
# 里面跑你的脚本，然后按 Ctrl-b 再按 d 脱离
tmux attach -t train              # 回来重新接上
```

💪 为什么比默认方式好
不用 nohup 重定向日志、也不用开一堆终端窗口，断线重连后输出和分屏原样保留。

🧪 数据科学场景
在实验室服务器上跑几小时的模型训练或数据清洗脚本，本地 Mac 合盖走人，回来 `tmux attach` 直接看进度；同时用 `Ctrl-b %` 左右分屏，一边跑脚本一边开 `htop` 盯内存。
