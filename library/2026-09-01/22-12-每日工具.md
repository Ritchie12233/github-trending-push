🎯 解决什么痛点
不用在浏览器和编辑器之间来回切换，变量和图表直接嵌在代码旁，调试效率翻倍。

⚡ 快速上手
```bash
# 安装 VS Code 后，打开任意 .ipynb 文件即可
# 启用变量浏览器：点击顶部“变量”图标，或运行：
# 交互绘图需安装 ipympl
pip install ipympl
%matplotlib widget
```

💪 为什么比默认方式好
对比 Jupyter Notebook：VS Code 内联支持代码折叠、Git 版本控制、远程 SSH 调试，且变量浏览器实时刷新，无需手动刷新页面。

🧪 数据科学场景
跑 EDA 时，一边用 `df.head()` 看数据，一边用 `plt.scatter()` 画分布图，变量和图表同屏显示，快速发现缺失值和异常点，不用切窗口打断思路。
