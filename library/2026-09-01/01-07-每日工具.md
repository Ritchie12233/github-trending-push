🎯 解决什么痛点
调试代码时，看到一行报错却不知道是谁、何时、为何改的，翻 Git 日志效率极低。

⚡ 快速上手
在 VS Code 扩展市场搜索 “GitLens” 安装，或终端执行：
```bash
code --install-extension eamodio.gitlens
```
安装后，点击编辑器右侧的 “GitLens” 图标，或直接悬停代码行尾即可看到 blame 信息。

💪 为什么比默认方式好
VS Code 内置 Git 只显示文件级历史，GitLens 直接内联到每一行，省去 `git log -L` 的繁琐命令。

🧪 数据科学场景
当你复现别人 notebook 或协作项目时，某行数据预处理逻辑突然出错，GitLens 能瞬间定位到是队友哪次 commit 改动了特征缩放，直接查看 commit message 了解原因，避免盲猜。
