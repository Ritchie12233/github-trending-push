🎯 解决什么痛点
终端里 print 出来的 DataFrame、日志、进度全是黑白纯文本，看不清结构、不知道跑到哪了。

⚡ 快速上手
```bash
pip install rich
```
```python
from rich import print
from rich.table import Table

print("[bold green]模型训练完成[/bold green]", {"accuracy": 0.93})
```

💪 为什么比默认方式好
不用手写对齐空格和 ANSI 颜色码，一行 print 自动上色、自动排版。

🧪 数据科学场景
用 `rich.progress` 给 pandas 逐行处理或模型训练加进度条，用 `rich.table` 把评估指标（precision/recall/F1）打印成整齐表格，比裸 print 一眼看清结果。
