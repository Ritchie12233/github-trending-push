🎯 解决什么痛点
在大型数据集或代码库中搜索关键词时，grep 慢且被 .gitignore 文件干扰，rg 快 10 倍且自动跳过无用文件。

⚡ 快速上手
```bash
# 安装（macOS）
brew install ripgrep

# 搜索 Python 文件中含 "pandas" 的行，显示行号
rg "pandas" --type py -n
```

💪 为什么比默认方式好
比 grep 快一个数量级，且默认遵守 .gitignore，无需手动排除 node_modules 或 .venv。

🧪 数据科学场景
在 Jupyter notebook 或项目里快速定位某个函数/变量定义，或搜索所有 CSV 文件中的特定列名，秒出结果。
