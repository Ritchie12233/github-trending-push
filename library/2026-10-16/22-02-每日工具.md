🎯 解决什么痛点
临时算个数（比如算准确率、换算单位）不用切窗口、不用打开计算器 App，思路不被打断。

⚡ 快速上手
按 `Cmd + Space` 呼出 Spotlight，直接输入算式，回车即可复制结果：
```
(45/50)*100
```
支持 `+ - * /`、括号、百分号，甚至单位换算：
```
120 usd to myr
```

💪 为什么比默认方式好
比打开「计算器」App 快得多——不用切窗口、不用点按钮，键盘流一气呵成。

🧪 数据科学场景
跑模型时随手核对指标：算 accuracy、precision、百分比变化，或把论文里的美元金额换算成马币，全程不离开编辑器。
