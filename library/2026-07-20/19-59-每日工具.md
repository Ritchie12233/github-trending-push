🎯 解决什么痛点
训练模型到一半，SSH 断连或合上 MacBook，进程全丢，得从头跑。

⚡ 快速上手
```bash
# 安装
brew install tmux

# 创建会话并跑任务
tmux new -s train
python train.py

# 断开（Ctrl+B 再按 D），任务继续跑
# 重新连回
tmux attach -t train
```

💪 为什么比默认方式好
nohup 无法分屏、无法重连已有进程；Screen 功能更弱且维护少。tmux 是行业标准。

🧪 数据科学场景
在远程服务器上跑 8 小时的特征工程或模型训练，断开 Mac 回家，回来 `tmux attach` 继续看日志。
