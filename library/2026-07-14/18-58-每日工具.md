🎯 解决什么痛点
代码检查+格式化需要装 flake8、black、isort 三个工具，配置繁琐且运行慢。

⚡ 快速上手
```bash
pip install ruff
ruff check .          # 检查代码问题
ruff format .         # 自动格式化代码
```

💪 为什么比默认方式好
速度比 flake8+black 快 10-100 倍，一个工具搞定 lint + format + import 排序，零配置开箱即用。

🧪 数据科学场景
Jupyter Notebook 导出 .py 文件后，一行 `ruff format script.py` 秒清混乱缩进和 import 顺序，省去手动整理时间。
