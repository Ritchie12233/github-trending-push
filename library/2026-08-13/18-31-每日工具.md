🎯 解决什么痛点
用一行代码替代多层嵌套 for 循环，处理迭代、分组、笛卡尔积等操作，代码更简洁高效。

⚡ 快速上手
```python
from itertools import chain, groupby, product

# 合并多个列表
list(chain([1,2], [3,4]))  # [1,2,3,4]

# 按键分组（需先排序）
data = [('a',1), ('a',2), ('b',3)]
for k, g in groupby(data, key=lambda x: x[0]):
    print(k, list(g))  # a [(a,1),(a,2)], b [(b,3)]

# 笛卡尔积（替代嵌套循环）
list(product([1,2], ['x','y']))  # [(1,'x'),(1,'y'),(2,'x'),(2,'y')]
```

💪 为什么比默认方式好
手写循环代码冗长且易错，itertools 基于 C 实现，内存高效（惰性求值），性能更优。

🧪 数据科学场景
- **特征组合**：`product` 快速生成超参数网格（如学习率×正则化系数）
- **数据清洗**：`chain` 合并多个 CSV 文件的行迭代器，避免一次性加载内存
- **时间序列**：`groupby` 按日期或类别聚合数据，配合 pandas 做预处理
