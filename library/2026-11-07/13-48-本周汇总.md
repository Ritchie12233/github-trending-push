**1. 代码知识图谱** — 代码库转可查询图谱（⭐144k）
- **是什么**：把任意代码库（含文档、SQL schema、配置文件、PDF）解析成可查询的知识图谱，通过 AST 本地确定性解析，每条边都有解释，不依赖向量数据库。提供 Claude Code / Cursor / Codex / Gemini CLI 的 `/graphify` 技能。
- **为什么必看**：对数据科学研究生极其友好——你可以把整个项目仓库（含 Jupyter notebook、SQL 建表脚本、数据字典 PDF）一次性转成图谱，然后用自然语言查询「哪些特征工程代码依赖这个原始表」。相比传统 RAG，图谱方式对代码结构关系（调用链、数据血缘）的保留更完整，做数据管道溯源、复现实验时非常实用。
- **怎么用**：先在一个小项目上跑 `/graphify`，观察生成的图谱节点/边是否符合预期；再尝试对含 SQL schema 的数据项目做查询，验证数据血缘追踪效果。

**2. 从零实现LLM** — PyTorch手写大模型教程（⭐108k）
- **是什么**：用 PyTorch 从零一步步实现一个类 ChatGPT 的 LLM，覆盖 tokenizer、注意力机制、预训练、指令微调全流程，配套 Jupyter Notebook。
- **为什么必看**：这是理解 Transformer 内部机制最扎实的路径。对数据科学研究生而言，光会调 `transformers` 库不够，理解 attention 的计算细节、tokenizer 的分词逻辑，才能在论文复现或模型微调时定位问题。代码可逐行运行，适合边读边改。
- **怎么用**：不要一口气读完，按章节推进——先跑通 tokenizer 和 attention 两章，把中间张量形状打印出来对照论文公式，再继续预训练部分。

**3. 数据科学精选** — 真实问题学习资源库（⭐30k）
- **是什么**：面向真实世界问题的数据科学资源合集，涵盖数据挖掘、可视化、深度学习、机器学习等主题的教程、数据集与工具链接。
- **为什么必看**：作为数据科学研究生，这是你构建「知识地图」的索引型资源。它的价值不在单篇教程，而在于帮你快速定位某个子领域（如时间序列、因果推断）的入门材料与数据集，避免在搜索上浪费时间。
- **怎么用**：不要通读，用「按需检索」的方式——做课程项目或论文选题时，先来这里找对应子领域的资源清单，再深入。

**4. 智能体工作流** — 可视化RAG与Agent编排（⭐161k）
- **是什么**：可视化构建 Agentic 工作流与 RAG 管道的协作平台，支持丰富模型与工具，可云端/自托管部署，从原型到生产无需重建技术栈。
- **为什么收藏**：如果你要做「LLM + 数据检索」的课程项目或论文原型，Dify 能让你在几小时内搭出可演示的 RAG 系统，省去前端和后端胶水代码。但生产级调优仍需理解底层，所以归为收藏而非必看。
- **怎么用**：先用它快速搭一个「论文库问答」demo 验证想法，再决定是否深入自建。

**5. 数据分析平台** — 开源BI与数据探索（⭐75k）
- **是什么**：Apache Superset，数据可视化与数据探索平台，支持 SQL 编辑器、丰富图表类型、仪表盘。
- **为什么收藏**：数据科学研究的最后一步往往是「把结果讲清楚」。Superset 让你用 SQL 直接连数据库出图，比手写 matplotlib 更适合做可交互的探索性分析汇报。学习曲线中等，值得提前 bookmark。
- **怎么用**：用 Docker 起一个本地实例，连上你常用的数据集，练习做一个多图仪表盘。

**6. 机器学习精选** — 每周更新的ML库排名（⭐24k）
- **是什么**：按类别排名的机器学习 Python 库清单，每周自动更新，覆盖 AutoML、数据可视化、NLP、深度学习等。
- **为什么收藏**：选型时的「避坑指南」。当你要为某个任务选库（比如做时间序列预测），这里能快速看到社区活跃度排名，避免选到已停止维护的库。
- **怎么用**：收藏为书签，每次新项目选型前扫一眼对应类别。

**7. 数据管道编排** — Python工作流调度框架（⭐24k）
- **是什么**：Prefect，用 Python 构建弹性数据管道的 workflow orchestration 框架，支持调度、可观测性、失败重试。
- **为什么收藏**：数据科学研究的「工程化」门槛。当你的实验从单脚本变成「抓数据→清洗→训练→评估」多步骤流程时，Prefect 比 cron + 手写脚本可靠得多。相比 Airflow 更轻量、Pythonic，适合研究生个人项目。
- **怎么用**：先把一个现有的多步骤实验脚本改写成 Prefect flow，体会任务依赖与重试机制。

**8. 算法动画图解** — 多语言数据结构教程（⭐132k）
- **是什么**：《Hello 算法》，动画图解、一键运行的数据结构与算法教程，支持简中/繁中/英/日，提供 Python、Java、C++ 等十余种语言实现。
- **为什么新人友好**：非 CS 背景研究生补数据结构的最佳入口——动画把抽象过程可视化，代码可一键运行，中文文档完整。学扎实了对理解 pandas 底层、写高效数据预处理代码都有帮助。
- **怎么用**：每天花 20 分钟看一个数据结构章节，重点看「数组与链表」「哈希表」「二叉树」，这三块与数据处理最相关。

**9. ML零基础课** — 12周26课机器学习入门（⭐92k）
- **是什么**：微软 ML-For-Beginners，12 周 26 课 52 个测验的经典机器学习课程，用 scikit-learn 和 R 实现。
- **为什么新人友好**：结构化的课程设计 + 测验机制，适合系统补齐 ML 基础。对数据科学研究生来说，如果你本科非统计/CS 背景，这门课能帮你把「监督/无监督、回归/分类、过拟合」等概念理清楚。
- **怎么用**：跳过你已掌握的部分，重点做每课的 quiz 和配套 notebook，用 scikit-learn 亲手跑一遍。

📖 学习建议
1. **先补「数据血缘」意识再谈 AI**：本周的代码知识图谱项目提醒我们，数据科学项目的可复现性瓶颈往往不在模型，而在「这个特征从哪张表、哪段代码来的」。建议你选一个现有项目，手动画出数据从原始表到最终特征的流转图，再尝试用图谱工具自动化——这个练习对写论文的「可复现性」章节极有帮助。
2. **用「从零实现LLM」做一次深度阅读**：不要只跑通代码，选 attention 那一章，把每个矩阵乘法的维度手写推导一遍，再对照 `transformers` 库的源码看差异。这种「从零到库」的对照阅读，是非 CS 背景研究生跨越「会用」到「懂原理」最有效的方式。
