🎯 解决什么痛点
`git diff` 默认输出黑白纯文本，改动一多就分不清哪行加了、哪行删了，代码审查和回顾自己的改动都很费眼。

⚡ 快速上手
```bash
brew install git-delta
# 写入 git 配置，之后所有 git diff / git log 自动美化
git config --global core.pager delta
git config --global interactive.diffFilter "delta --color-only"
```

💪 为什么比默认方式好
原生 diff 只有 +/- 符号，delta 用红绿底色、行号、语法高亮并排展示，一眼看清改动。

🧪 数据科学场景
改完 notebook 转出的 `.py` 脚本或 `requirements.txt` 后，用 `git diff` 快速确认这次到底动了哪几行、有没有误删依赖，比在 GitHub 网页上翻更即时。
