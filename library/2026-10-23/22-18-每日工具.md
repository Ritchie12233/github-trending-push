🎯 解决什么痛点
同一个函数被反复调用相同参数时重复计算，白白浪费时间——加一行装饰器就能缓存结果。

⚡ 快速上手
```python
from functools import lru_cache

@lru_cache(maxsize=None)
def slow_square(n):
    return n ** 2
```
（内置库，无需安装；`maxsize=None` 表示不限缓存条数）

💪 为什么比默认方式好
比手写字典缓存少写样板代码，还自带 LRU 淘汰策略和命中统计。

🧪 数据科学场景
特征工程里反复调用的清洗/映射函数、递归计算（如斐波那契、动态规划）、以及参数固定的模型预处理步骤，第二次调用直接返回缓存结果。
