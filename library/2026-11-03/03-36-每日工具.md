🎯 解决什么痛点
记不住完整命令、文件名或 Git 分支名时，不用再翻历史记录或一个个 `ls` 找，输入几个模糊字符就能秒选。

⚡ 快速上手
```bash
brew install fzf && $(brew --prefix)/opt/fzf/install   # 安装并启用 Ctrl+R / Ctrl+T
# 之后：Ctrl+R 模糊搜历史命令，Ctrl+T 模糊选文件，git checkout $(git branch | fzf) 切分支
```

💪 为什么比默认方式好
默认 Ctrl+R 只能顺序匹配、`ls | grep` 要精确拼写；fzf 支持模糊匹配 + 实时预览，一步选中。

🧪 数据科学场景
在几十个 `notebook_*.ipynb`、`data_*.csv` 里用 Ctrl+T 直接模糊定位文件并插入路径；`jupyter notebook $(ls *.ipynb | fzf)` 秒开目标 notebook，不用记全名。
