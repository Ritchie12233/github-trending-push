🎯 解决什么痛点
API 返回一大坨 JSON，肉眼找字段找到崩溃，Python 写脚本又嫌重。

⚡ 快速上手
```bash
brew install jq
curl -s "https://api.github.com/users/torvalds" | jq '.name, .public_repos'
```

💪 为什么比默认方式好
不用写 Python、不用打开浏览器，一行管道直接提取字段，比 `python -m json.tool` 强在能查询和过滤。

🧪 数据科学场景
调 API 拿数据时，先用 jq 快速看清结构（有哪些字段、嵌套多深），再决定用 pandas 怎么解析——省掉反复 print 调试的时间。

```bash
# 看结构
curl -s "$API_URL" | jq 'keys'

# 提取嵌套字段成 CSV
curl -s "$API_URL" | jq -r '.[] | [.id, .name, .score] | @csv' > data.csv
```
