🎯 解决什么痛点
用 os.path 拼路径要写一堆字符串拼接和 `os.path.join()`，跨平台还容易踩斜杠坑。

⚡ 快速上手
```python
from pathlib import Path

data_dir = Path("~/datasets/titanic").expanduser()
df = pd.read_csv(data_dir / "train.csv")   # 用 / 拼路径，自动跨平台
print(data_dir.glob("*.csv"))              # 直接找文件，不用 os.listdir
```

💪 为什么比默认方式好
路径是对象不是字符串，`/` 拼接、`.glob()`、`.read_text()` 一步到位，比 os.path 少写一半代码。

🧪 数据科学场景
批量读取一个文件夹里的所有 CSV 做合并分析：
```python
import pandas as pd
from pathlib import Path

folder = Path("~/project/raw_data").expanduser()
df = pd.concat([pd.read_csv(f) for f in folder.glob("*.csv")], ignore_index=True)
```
比 `os.listdir` + 手动拼路径清爽太多，换 Mac/Windows 也不用改代码。
