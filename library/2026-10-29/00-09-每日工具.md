🎯 解决什么痛点
pandas 处理百万行以上数据时又慢又吃内存，polars 用 Rust 多核并行，同样数据快 5–10 倍、内存省一半。

⚡ 快速上手
```python
pip install polars
import polars as pl
df = pl.read_csv("data.csv").filter(pl.col("score") > 80).group_by("major").agg(pl.col("score").mean())
```

💪 为什么比默认方式好
惰性执行 + 多线程，不用改写法就能跑满 CPU；pandas 单核且常爆内存。

🧪 数据科学场景
清洗几百万行的课程/问卷/日志数据、做特征工程时，`pl.scan_csv` 惰性加载只算需要的列，Mac 上不再风扇狂转、内存告急。
