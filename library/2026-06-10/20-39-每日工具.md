🎯 解决什么痛点
终端看代码文件时没有颜色、没有行号，眼睛累，找错行困难。

⚡ 快速上手
```bash
brew install bat
bat data_cleaning.py   # 直接查看 Python 文件，自动高亮+行号
```

💪 为什么比默认方式好
cat 输出纯黑白文本，bat 自动识别 100+ 语言语法高亮，自带行号和 Git 修改标记。

🧪 数据科学场景
快速预览 `.py`、`.ipynb`、`.csv`、`.yaml` 配置文件，不用打开 IDE 就能看清代码结构和数据格式。
