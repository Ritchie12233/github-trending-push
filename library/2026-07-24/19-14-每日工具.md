🎯 解决什么痛点
数据集和日志文件越存越多，磁盘突然爆满，却不知道哪些文件在吃空间。

⚡ 快速上手
```bash
brew install ncdu   # 安装
ncdu ~/data         # 扫描指定目录，按方向键浏览，d删除文件
```

💪 为什么比默认方式好
`du -sh *` 只能看一层，ncdu 交互式浏览、可排序、可删除，效率高10倍。

🧪 数据科学场景
训练完几个模型后，`~/data/raw` 和 `~/models/checkpoints` 占了多少？`ncdu ~` 一秒定位，直接清理无用缓存和中间文件。
