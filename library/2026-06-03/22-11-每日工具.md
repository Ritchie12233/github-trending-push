🎯 解决什么痛点
手动写 `__init__`、`__repr__`、`__eq__` 等样板代码，数据类定义冗长且易出错。

⚡ 快速上手
```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    age: int
    gpa: float = 0.0

s = Student("Alice", 22, 3.8)
print(s)  # Student(name='Alice', age=22, gpa=3.8)
```

💪 为什么比默认方式好
一行装饰器自动生成 `__init__`、`__repr__`、`__eq__`，代码量减少 60%+。

🧪 数据科学场景
定义特征工程中的中间数据结构（如 `FeatureConfig`、`ModelParams`），替代字典避免键名拼写错误，配合 `asdict()` 直接转 DataFrame。
