🎯 解决什么痛点
不用再记或敲长路径，输入模糊关键词就能跳到最常去的目录。

⚡ 快速上手
```bash
# 安装
brew install zoxide

# 在 ~/.zshrc 添加一行，然后 source ~/.zshrc
eval "$(zoxide init zsh)"

# 使用：跳转到最常去的 data 目录
z data
```

💪 为什么比默认方式好
`cd` 需要完整路径或手动 tab 补全；zoxide 用模糊匹配+频率排序，一次回车直达。

🧪 数据科学场景
每天在 `~/projects/eda/`、`~/datasets/raw/`、`~/notebooks/` 之间反复切换，只需 `z eda`、`z raw`、`z note` 即可跳转，省去每次 `cd ../../` 的麻烦。
