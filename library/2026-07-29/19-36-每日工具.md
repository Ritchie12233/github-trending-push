🎯 解决什么痛点
每次写数据加载、绘图、模型训练都要重复敲相同模板代码，浪费时间且容易漏写参数。

⚡ 快速上手
在 VS Code 中按 `Cmd+Shift+P` → 搜索“配置用户代码片段” → 选择 `python.json`，粘贴：
```json
"Load CSV": {
  "prefix": "lcsv",
  "body": [
    "import pandas as pd",
    "df = pd.read_csv('$1.csv')",
    "df.head()",
    "$0"
  ],
  "description": "快速加载CSV并预览"
}
```
之后在 `.py` 文件输入 `lcsv` 按 Tab 即可展开。

💪 为什么比默认方式好
比手动复制粘贴快3倍，且参数占位符（`$1`）让你一键跳转到文件名位置修改。

🧪 数据科学场景
写 EDA 时，输入 `edat` 自动展开 `df.info(), df.describe(), df.isnull().sum()` 三连，省去每次敲重复代码。
