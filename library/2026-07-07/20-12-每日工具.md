🎯 解决什么痛点
重复调用相同参数的函数时，每次都重新计算，浪费时间和算力。

⚡ 快速上手
```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)
```

💪 为什么比默认方式好
一行代码自动缓存结果，无需手动写字典或第三方库，内存友好且线程安全。

🧪 数据科学场景
递归特征工程、动态规划算法（如序列对齐）、或重复调用相同参数的模型预测时，缓存中间结果，秒级提速。
