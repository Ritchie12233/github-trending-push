🎯 解决什么痛点
每天重复敲长命令（如 `ls -lah`、`git log --oneline`），浪费时间且容易打错。

⚡ 快速上手
```bash
# 在 ~/.zshrc 中添加（Mac 默认 zsh）
alias ll='ls -lah'
alias gs='git status'
alias jn='jupyter notebook'
# 生效
source ~/.zshrc
```

💪 为什么比默认方式好
把 10+ 字符缩成 2 个字母，每天省下上百次按键，零学习成本。

🧪 数据科学场景
- `alias jn='jupyter notebook'`：秒开 Notebook
- `alias pd='python -c "import pandas as pd; print(pd.__version__)"'`：快速检查 pandas 版本
- `alias ds='du -sh * | sort -h'`：一键查看当前目录各文件/文件夹大小（清理数据集时极有用）
