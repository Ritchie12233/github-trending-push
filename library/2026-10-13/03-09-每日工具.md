🎯 解决什么痛点
不同项目依赖的库版本互相打架，装了这个项目跑不了那个项目。

⚡ 快速上手
```bash
# 在项目文件夹里创建并激活（Mac）
python3 -m venv .venv && source .venv/bin/activate
pip install pandas scikit-learn   # 依赖只装进这个环境
```

💪 为什么比默认方式好
全局 pip 装一次污染所有项目，venv 让每个项目自带独立依赖，删文件夹即卸载。

🧪 数据科学场景
课程作业 A 要 scikit-learn 0.24、毕业论文要 1.3，各自建一个环境，切换时 `source .venv/bin/activate` 即可，互不干扰；配合 `pip freeze > requirements.txt` 还能一键复现环境交给导师或同学。
