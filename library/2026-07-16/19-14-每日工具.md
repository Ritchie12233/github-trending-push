🎯 解决什么痛点
用 `cat` 看 Python 脚本或 CSV 文件时，满屏白字，没有行号，找错行全靠数。

⚡ 快速上手
```bash
brew install bat          # 安装
bat data/eda.py           # 查看 Python 文件
bat --line-range 10:20 data/eda.py  # 只看 10-20 行
```

💪 为什么比默认方式好
`cat` 输出纯文本，`bat` 自动识别 200+ 语言语法高亮，自带行号和 Git 修改标记。

🧪 数据科学场景
快速预览 `.py` 脚本或 `.json` 配置文件时，高亮让变量名、函数、注释一目了然，配合 `--line-range` 只看关键代码段，省去在 IDE 里打开的时间。
