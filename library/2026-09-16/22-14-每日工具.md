🎯 解决什么痛点
数据脏、字段缺、类型乱——pydantic 在数据进入你的分析流程前就自动校验和转换，省掉一堆手写 if 判断。

⚡ 快速上手
```bash
pip install pydantic
```
```python
from pydantic import BaseModel

class Student(BaseModel):
    name: str
    age: int
    gpa: float = 3.0

s = Student(name="Ali", age="23")   # 自动把 "23" 转成 int
print(s.age + 1)                     # 24
```

💪 为什么比默认方式好
比 dataclass 多了自动类型转换和校验，比手写 assert 更简洁、报错更清晰。

🧪 数据科学场景
读取 CSV/API 返回的原始数据时，用 pydantic 定义 schema，一次性过滤掉缺失值、错误类型和越界数据，避免脏数据污染后续建模。配合 FastAPI 部署模型 API 时，请求参数自动校验，几乎零额外代码。
