🎯 解决什么痛点
不想为每个脚本手写 argparse 参数解析，希望用函数签名直接生成命令行工具。

⚡ 快速上手
```bash
pip install typer
```
```python
import typer

def main(name: str, age: int = 20):
    print(f"{name} is {age} years old")

if __name__ == "__main__":
    typer.run(main)
```
运行：`python script.py Alice --age 25`

💪 为什么比默认方式好
比 argparse 代码量减少 80%，类型注解自动生成帮助文档和参数校验。

🧪 数据科学场景
快速将数据清洗函数变成可复用 CLI，比如 `python clean.py data.csv --drop-na --out result.csv`，方便团队非技术成员直接调用。
