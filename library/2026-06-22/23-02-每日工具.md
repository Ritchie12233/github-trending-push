🎯 解决什么痛点
不用在浏览器和编辑器之间来回切换，所有代码、输出、变量都在 VS Code 里完成。

⚡ 快速上手
在 VS Code 中打开 `.ipynb` 文件，或新建一个 Python 文件，在代码块上方点击 `Run Cell` 即可运行。

💪 为什么比默认方式好
比 Jupyter Notebook 网页版快 3 倍启动速度，且变量浏览器可实时查看 DataFrame 形状、列名、缺失值，无需手动 `df.head()`。

🧪 数据科学场景
清洗数据时，一边用 `df.isnull().sum()` 检查缺失值，一边在变量浏览器里双击变量展开查看，不用反复打印。
