🎯 解决什么痛点
`man` 手册冗长难读，查命令用法像翻字典，浪费时间。

⚡ 快速上手
```bash
# 安装（macOS）
brew install tldr

# 查看 tar 命令的常用示例
tldr tar
```

💪 为什么比默认方式好
`man` 给全量参考，`tldr` 给精选示例，3秒上手，省去翻页痛苦。

🧪 数据科学场景
写 Python 脚本时，快速回忆 `grep`、`find`、`jq` 等命令的常用参数，不用中断思路去查文档。
