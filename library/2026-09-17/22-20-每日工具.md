🎯 解决什么痛点
同一个函数被反复调用相同参数时重复计算，白白浪费时间。

⚡ 快速上手
```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)
```

💪 为什么比默认方式好
一行装饰器搞定缓存，无需手动维护字典或引入第三方库。

🧪 数据科学场景
特征工程里反复调用同一个数据清洗/编码函数、递归计算、或加载固定参数模型时，第二次调用直接命中缓存，速度提升几十倍。
