🎯 解决什么痛点
处理超过内存或几GB的大数据集时，pandas 慢到让人怀疑人生，polars 用多线程和惰性计算让速度提升数倍到数十倍。

⚡ 快速上手
```bash
pip install polars
```
```python
import polars as pl
df = pl.read_csv("big_data.csv")
# 惰性查询，自动优化执行计划
result = (df.lazy()
            .filter(pl.col("value") > 100)
            .group_by("category")
            .agg(pl.col("value").mean())
            .collect())
```

💪 为什么比默认方式好
pandas 单线程+急切执行，polars 多核并行+查询优化器，速度碾压且内存占用更低。

🧪 数据科学场景
处理百万行以上的日志或传感器数据时，用 `scan_csv` 流式读取 + 惰性操作，避免内存爆炸，快速完成清洗和聚合。
