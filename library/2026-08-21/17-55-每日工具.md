🎯 解决什么痛点
`cat` 看代码全是白底黑字，没有高亮和行号，读长文件眼睛累且难定位。

⚡ 快速上手
```bash
# macOS 安装
brew install bat

# 直接查看 Python 文件（自动识别语法）
bat model.py

# 显示行号并跳转到第 50 行
bat -n -r 50:60 train.py
```

💪 为什么比默认方式好
`cat` 输出纯文本，`bat` 自动高亮 + 行号 + Git 修改标记，一眼看清代码结构。

🧪 数据科学场景
快速 review 队友的 `pipeline.py` 或 `config.yaml`，不用打开 IDE，终端里直接高亮阅读，配合 `grep` 搜索结果管道使用更香：
```bash
grep -n "def " *.py | bat
```
